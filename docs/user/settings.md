# Settings

Part of [TextMouth's documentation](../../README.md).

Settings has these tabs.

- Voice, Playback, Shortcuts, Text (substitution rules and repeated symbols), Sounds, Stats (listening time, streak, and books finished), Feeds (podcast and article feeds), Storage, and Miscellaneous. Every tab but Text scrolls when it is taller than the window, its groups in boxes, and Tab, and VoiceOver as it moves, bring each control into view; the Text tab's rule list scrolls by itself. A slider is labelled by its setting alone, as "Speed" or "Bluetooth disconnect delay", since VoiceOver names the kind of control itself, and the value shown beside a slider is read once, as the slider's value, with its unit.
- The Shortcuts tab changes the shortcuts for reading, navigation, bookmarks, the sleep timer, information (Where Am I?, Where Am I? Full Summary, Speak Info, Speak Full Info, Speak Import Progress, and Speak Download Progress), the library's actions, the File menu's Open Book…, New from Text…, and New Recording…, the New Recording window's buttons, under New Recording, the window's name, and the audio editor, whose group, Audio Editor, works only in an editor window (see [Editing audio](editing-audio.md)). A key set there acts before the menus see it, except a menu command's. Open Book…, New from Text…, and New Recording… (under File), Import Folder… and Add Feed… (under Library), Copy Reading Position and Search in Book (under Playback), and the New Recording window's Record, Pause or Resume, and Stop (under New Recording) keep their keys in their menu items, which show the key in force, as VoiceOver reads it, and in that window's buttons, whose hints name the key in force. Each holds one key, one press of a key with Command or Control that a text field doesn't edit with, and any other is refused, saying why, as in "W not recorded for Open Book…: a menu command's shortcut is one press of a key with Command or Control." or "Control + A not recorded for Open Book…: a text field edits with it, and a menu command's shortcut would take it from the field." No shortcut may take a key one of macOS's own commands has in the menus, unless it is that action's own default, as Select All's Command-A is: Quit (Command-Q), Close (Command-W), Close All (Option-Command-W), Settings (Command-Comma), Hide (Command-H), Hide Others (Option-Command-H), Minimize (Command-M), Minimize All (Option-Command-M), and the Edit menu's Undo (Command-Z), Redo (Shift-Command-Z), Cut (Command-X), Copy (Command-C), Paste (Command-V), Paste and Match Style (Option-Shift-Command-V), and Select All (Command-A), as in "Command + Q not recorded for Where Am I?: Quit TextMouth has it in the menus, and no shortcut may take it." TextMouth keeps a record of the shortcuts you change, and only those, and a shortcut can be one key pressed twice:
  - Each action's row has a VoiceOver label in words: its name, then its keys, with special keys by name, as in "Skip Forward: Command + Right Arrow or L", where the screen shows symbols. Punctuation is said in words too, as in "Go Back: Command + Left Bracket", where the screen shows the mark itself, and so are Forward Delete, Home, End, Page Up, Page Down, Help, Clear, the F keys, and the keypad's Enter, which the screen names in words as well, as "Page Down" or "F5". A key pressed twice is said and shown with "twice" after it, as in "W twice".
  - A shortcut you change is marked Edited, after its keys on screen and at the end of its row's label, as in "Release Media Controls: Shift + R. Edited.", and stays yours, even set back to its default keys, until you give it back. Reset to Default, a button on each edited row and one of the row's actions in VoiceOver's Actions menu (VO-Command-Space), gives the action back TextMouth's default keys, less any that an action you changed holds, and says the keys it has then, as in "Next Bookmark reset to default: Option + Shift + Command + B." Reset to Defaults, at the end of the tab, asks first, then gives every action back its default keys and where it works by default.
  - Every shortcut you haven't changed follows TextMouth's defaults, so a default that a later version adds or changes reaches it. Recording a key that another action working in any of the same windows had takes the key from that action and says so, as in "Command + B, recorded for Show Bookmarks. Taken from Toggle Bookmark." A menu command's key counts as pressed once and twice, so recording it as a double press takes it too, as in "Command + O twice, recorded for Book Info. Taken from Open Book…" An action you changed keeps its other keys; one you haven't isn't marked Edited for the loss, says on its row, on screen and to VoiceOver, which action has the key, as in "New from Text… has its default, Shift + Command + T.", and has the key again once the action that took it lets it go.
  - Reset to Defaults, at the foot of the tab, asks first, in an alert, "Reset Keyboard Shortcuts?", and then gives every action its default keys again; once the alert has closed, VoiceOver says "The keyboard shortcuts are reset to the defaults."
  - Works in, a pop-up button on the row of each action that can work in more than one kind of window, sets where its shortcuts work: Every window, Library windows, or Reader windows. Its label is "Works in", its value the choice, as in "Library windows" on New from Text…'s row, and its hint "Where this shortcut works. Choosing makes it yours; Reset to Default gives back where it works by default." By default New from Text… works in Library windows and Show Sleep Timer in reader windows, so Shift-Command-T is each one's in its own kind of window. Import Folder… and Add Feed… always work in Library windows, and Copy Reading Position and Search in Book in reader windows, where their menus are; the audio editor's actions work in its windows, and the New Recording window's buttons in that window. Every other action works by default in every window but an audio editor's, though a File menu command that works in every window, as Open Book… and New Recording… do by default, works in an audio editor's window too, as menus do, and any menu command works when no window is open. So such a command's key is its own in an editor's window too: giving it a key an editor action has takes the key from that action, as in "Command + S, recorded for Open Book… Taken from Audio Editor: Save." A sheet uses the shortcuts of the window it is over, and a sheet over a sheet those of the window under them both, though no shortcut works in a sheet over an audio editor's window. A row's VoiceOver label says where its action works when that is Library or reader windows, or other than its default, as in "Show Sleep Timer: Shift + Command + T. Works in reader windows." Choosing makes the action yours and takes its keys from any other action that works in any of the same windows, as in "New from Text… works in every window. Taken from Show Sleep Timer." Reset to Default gives back where it works too, as in "New from Text… reset to default: Shift + Command + T. Works in Library windows." A menu command set to work elsewhere is dimmed, and shows no key, in other kinds of window, so there its key reaches the window's own shortcut. In a Library window, whatever Works in says, no shortcut that is a letter pressed alone runs, once or twice: the list takes the letter and moves to the first book or folder whose name starts with it (see [The Library window](library-window.md)). So W, J, K, L, F, and B, the defaults that are a letter alone, work in reader windows only, while a letter with Shift, Option, Command, or Control still runs its shortcut in a Library window.
  - The first time TextMouth keeps this record on a Mac, it makes it from every action's keys as saved before, in its preferences and in config.json, taking the file's keys for an action you changed in the file while TextMouth was closed, and then saves config.json in its new form (see [Editing settings in config.json](config-json.md)). An action whose saved keys were its default, today's or an earlier one, or that default less a key you gave another action, counts as never changed and follows today's defaults: a Next Bookmark saved with Shift-Command-B, its default until March 24, 2026, takes today's Option-Shift-Command-B and leaves Shift-Command-B to Show Bookmarks. The old copy in the preferences stays as it was, and TextMouth never writes it again. When config.json is already in the new form, as another Mac sharing the library writes it, the record is made from the file instead.
  - Double press time, at the top of the tab, sets how soon a second press of a key must follow the first to make a double press: half a second until you choose another, from 0.2 to 2 seconds in tenths, which VoiceOver speaks as "0.5 seconds" or "1 second". One time serves every shortcut.
  - A shortcut can be a key pressed twice, a double press. While a key's button records, its label is "Recording shortcut. Press a key, or press it twice for a double press.": one press is recorded once the double-press time has passed, a second press of the same key within that time records the double press, and another key pressed before then records the first key once. Escape cancels, a key held down never records twice, and no shortcut acts while a key is recorded. Each key's button also offers Make Double Press, or Make Single Press for a double press, in VoiceOver's Actions menu (VO-Command-Space) and in its context menu. Every key recorded or changed so is announced, as in "W twice, recorded for Go to Library." A menu command's row, and a New Recording window button's, holds one key and records differently: while its button records, its label is "Recording shortcut. Press a key with Command or Control.", the first press is recorded at once, and it offers no Make Double Press.
  - When one key's single press and double press belong to different actions, the single press waits out the double-press time before it acts, in case a second press follows, and VoiceOver says so as you set it up, as in "J now waits before Skip Backward, in case it is pressed twice." No default key waits, and a key whose double press runs the same action as its single press acts at once. So does one whose double press is the full summary of its single press: Where Am I? Full Summary is W twice and Speak Full Info Shift-Command-I twice, and the first press acts at once as Where Am I? or Speak Info, the second, within the double-press time, switching to the full summary, so neither key waits, whatever keys you give the pair. A key held down never counts as pressed twice, more quick presses after a double press are ignored, a key a text field keeps never counts as a press, and a double press with Command or Control works from a field, as other shortcuts with Command or Control do.
  - Try a Double Press, under the time, says "Press a key twice.", takes your next two key presses as no shortcuts, for five seconds, and says what they made: "Double press."; how far apart they came, as in "Two presses, 0.7 seconds apart. Set the time above 0.7 seconds to count them as one.", or, 2 seconds apart or more, that the time goes up to 2 seconds; "Two different keys. A double press is one key pressed twice."; or, when five seconds pass first, "No key was pressed twice." The text under the button keeps the last result, as in "Last try: Double press.", for a braille display to read again, until TextMouth quits; while a try waits for its presses, it reads "Press a key twice." A line of text under the button and its result, which VoiceOver and a braille display read, says why a letter shortcut does nothing in a Library window: "In Library windows, a letter pressed alone moves to the first book or folder whose name starts with it, so a shortcut that is a letter alone, such as W, works only in other windows."
  - Shift with the keys of Skip Forward, Skip Backward, and Increase Speed still triggers them, wherever they work, telling them Shift was held: Shift-J and Shift-L, and Shift with Command-Left Arrow or Command-Right Arrow, skip by the Playback tab's Shift units, and Increase Speed's Command-Plus works as a US keyboard types it, Shift-Command-Equal Sign. No other shortcut answers its key with Shift added, so outside an audio editor's window Shift-W and Shift-Command-Delete trigger no shortcut unless you give them to an action. A Shift shortcut of its own, such as a Shift-R you gave Release Media Controls, always wins; Shift never reaches a shortcut this way from a text field; and an audio editor's window matches only its own Shift keys, so there Shift-J and Shift-L are its own ten-second moves. In a Library window J and L are not shortcuts, so Shift-J and Shift-L fall back to nothing there. While a sheet or an alert is in front, no shortcut takes Return, the keypad's Enter, Escape, or Command-Period, which press its buttons.
- While a text field or text area has the keyboard, the Library's search field and every sheet's fields included, the keys that edit text are the field's and never act as shortcuts: Delete and Forward Delete, the arrows, Home, End, Page Up, and Page Down, with any modifiers; Command-A, Command-C, Command-V, Command-X, Command-Z, and Shift-Command-Z; and Control with A, B, D, E, F, H, K, L, N, O, P, T, V, or Y. So in the search field Command-Delete deletes to the start of the line rather than removing the selected books, Command-A selects the field's text rather than every book, and Command-Left Arrow and Command-Right Arrow move to the ends of the line rather than skipping. Every other shortcut with Command or Control works from a field, such as Command-I for Book Info, and a key with neither types in the field, as it always has. Leave the field, with Tab, to use those keys as shortcuts.
- The Storage tab's Audio Editing group sets how long the original audio of recordings and edited audiobooks is kept, whether an installed ffmpeg runs the audio editor's filters, whether the editor previews a filter before applying it and plays half a second after each move, and, through Filter Presets…, the editor's filter presets (see [Editing audio](editing-audio.md)).
- The Storage tab's Find Duplicate Books… groups the library's books, never a feed's episodes and articles, by the criteria you check: Identical File (MD5), checked as the sheet opens, Same ISBN, Same Title, and Same Author. Checked criteria combine, so Same Title with Same Author groups by both, and no separate Same Title & Author is offered; a book without an author is left out while Same Author is checked, so check Same Title alone to find two copies of it. Scan for Duplicates says how many duplicate groups it found, or that it found none; each group's heading names the criteria and what its books share, as in "Same Title and Same Author" over "Moby-Dick by Herman Melville"; each row speaks the book's title, author, format, folder, and the date it was added, which tells two copies apart, and the list keeps every row of the page it shows, so VoiceOver's cursor stays put in it; and the books you check, on every page, are moved to the Trash or deleted together, as Removal Behavior says, after asking when it says to. The groups are shown a page at a time: whole groups listing at most 40 books in all, or one larger group on a page of its own. While there is more than one page, a line above the list, shown and spoken alike, says which groups are shown, as in "Showing groups 1 to 5 of 116", and Previous Groups and Next Groups, each dimmed where there is no page to turn to, turn the page and announce the new line; each page opens at its top. After a removal, the list shows the page now holding the group that headed the page you were on. Before the first scan, the sheet says "Check the criteria above, then Scan for Duplicates."
- The Playback tab's Reader Toolbar section has Show Export in the reader toolbar, off by default, which puts an Export button in every reader's toolbar. File menu, Export… is there either way.
- The Playback tab's Times group has Include the speed with time left and total time, off by default, which names the speed those times count at beside them: on the reader's status row, as in "3:44:01 left at 2.0x", which VoiceOver reads as "at 2.0 times speed", or "at 500 words a minute" for a text book; in Where Am I?'s time left, and its full summary's total; in Copy Reading Position's time left; and in the Headings sheet's durations. An audiobook at 1x names nothing, and Where Am I?'s time left in the heading never names the speed.
- The Playback tab's Transcription group chooses the language audiobooks are transcribed in, and whether TextMouth offers to transcribe each audiobook it imports (see [Transcribing an audiobook](transcribing.md)).
- The Text tab's Repeated Symbols group sets how the voice reads one symbol written several times in a row, directly or with single spaces between, such as a separator line of asterisks. Say how many, the default, reads a run of 4 or more as a count, such as "7 asterisks"; Leave out skips the run with a pause; Repeat each symbol reads every one. "Collapse runs of at least" sets the shortest run that is counted or left out (2 to 99), and "Never collapse: read every symbol" reads every symbol whatever the style. The Symbols field lists the characters that can form runs; Reset to Default restores the standard list of ASCII symbols, bullets, dashes, the ellipsis, and box-drawing lines. Only speech changes: the text on screen and on a braille display keeps every symbol. A change applies from the next chapter spoken.
- The Text tab's Reset to Defaults asks first, naming how many rules it replaces, as in "The 15 rules in the list will be replaced by TextMouth's 16 default rules. Rules you added or changed will be lost." In a regular expression rule's replacement, $1, $2, and so on put back what each group of the pattern matched, as the replacement field's hint says, naming the dollar sign in words.
- The Miscellaneous tab's note under the restart timer gesture names the action that does the same from the keyboard as the Shortcuts tab names it: "The keyboard shortcut for the same action is Restart Sleep Timer in the Shortcuts tab; its default is Shift + Command + R."
- The Sounds tab's Reset to Defaults gives the sound assignments, the volume, and sounds on their defaults again at once, and VoiceOver says "The sound effects are reset to the defaults."
- The Stats tab's Books Finished This Year and Books Finished All Time count text books, audiobooks, and podcast episodes apart as well as together, under each count and spoken with it as one sentence, as in "7 books finished this year: 4 text books, 2 audiobooks, and 1 podcast episode". An article from a feed counts as a text book. A book finished before TextMouth counted kinds counts by its kind while it is in the library, and among other books once it has left. Books Finished counts each book once, however often it is finished, in the year it was first finished, and a rewind that replays a finished book's end counts nothing. Recently Finished lists the last ten books counted, newest first, each once, by the first time it was finished. The repeats an earlier version wrote, at each end of a book, stay in reading_stats.json and are counted once. Once on each Mac, after a launch's maintenance that has read reading_stats.json, TextMouth puts each book Books Finished counts whose row reads 100 percent exactly at its end, so it says Finished, keeping the date it was last opened, so Recently Opened, the Last Opened sort, and Speak Info stay as they were; while the statistics file is missing or cannot be read, nothing is moved, and the first launch that reads it makes the move; a book whose record is only in the cloud, or that is open in a window, waits for a later launch, and one whose content index disagrees with its row is left where it is.

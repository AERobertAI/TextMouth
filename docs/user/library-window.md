# The Library window

Part of [TextMouth's documentation](../../README.md).

- Choose a category, Folders, All Items, Unopened, Recently Opened, or Reading List, in the picker VoiceOver calls Library category. Unopened lists every book you have never opened, from every folder, and a book leaves it once you open it. It took the place of No Folder on October 7, 2026: the books in no folder, which No Folder listed, are at the top of the library in Folders. Recently Opened lists the ten books, episodes, and articles you opened last, and of each feed's episodes and articles only the one you opened last, which takes one of the ten places; it was called Recent until October 10, 2026, and keeps the sort you chose for it then. Where there are feeds, a Feeds section follows the folders, and in Unopened it lists a feed only while it has a new episode or article among those it lists, one published, or, undated, first seen, since you subscribed and neither played nor opened, so a podcast's back catalog never keeps it there (see [Podcasts and article feeds](feeds.md)). A feed's downloaded episodes and articles are listed in its feed's folder, and never in All Items, Unopened, or the top of Folders, where the feed's row stands for them; the Reading List lists one you add to it.
- Sort by title, author, date added, last opened, file size, or your own manual order. Each folder and category remembers its own sort, except the Reading List, which always shows the order you give it (below). Until you choose a sort in Unopened, it uses the sort you chose for No Folder, unless that was manual order, and otherwise sorts by date added, newest first. In the Sort menu a checkmark marks the field shown; choosing that field again keeps the sort as it is, and VoiceOver says the sort shown, as in "Sorted by Title, ascending". The item below the fields, Sort Descending or Sort Ascending, reverses the order; it is dimmed in manual order, which has no direction.
- A book's author comes from its file. An EPUB names its author in a creator element, or, in files some converters write, only in a dcterms:creator meta element or in a contributor marked as the author; TextMouth reads them all, since October 7, 2026, preferring a creator marked as the author to one listed before it, such as an illustrator, and reading a creator that says only Unknown as naming no one. On that day, 150 of a library's 729 EPUBs named their author in a meta element alone, and every one was listed under Unknown. A book whose file names no one is listed under Unknown, and Book Info, or an EPUB's metadata editor, lets you type an author in, which is kept whatever the file says.
- In manual order, Move Book Up and Move Book Down (Library menu, Shift-Command-Up Arrow and Shift-Command-Down Arrow), or dragging, rearrange a folder in Folders, the top of the library included, and at the Reading List they rearrange the list. All Items, Unopened, and Recently Opened mix books from many folders, which share no one order, so nothing rearranges them there.
- Where the list shows an order you arrange, a folder in manual order or the Reading List, a book's row also offers Move Up and Move Down in its context menu and as the first of its actions in VoiceOver's Actions menu (VO-Command-Space), each only where the book can make that move: the first book offers Move Down alone, and a book alone in the list offers neither. The VoiceOver actions move the book one place and say where it now stands, as in "Dune, 3 of 12"; the context menu's items, and Move Book Up and Move Book Down from the Library menu or the keyboard, say which book the move passed, as in "Moved Dune above Almanac". Should the list change after the row offered a move it can no longer make, the action says so, as in "Dune can't move up."
- Reading List, the fifth category, lists books from any folder in an order you arrange, each book once. Add to Reading List, in a book's context menu, its actions in VoiceOver's Actions menu, and the Library menu, adds the selected books to its end, and Remove from Reading List takes them off it, leaving them in the library. For several books selected, each command counts them, as in "Add 3 Books to Reading List", and a selection holding books of both kinds offers both. VoiceOver says what changed, as in "Added to reading list: Moby-Dick", or why nothing did, as in "Moby-Dick is already in the reading list." Neither command has a key until you give it one in the Shortcuts tab of Settings, under Library. In every other category, a book in the list says "In reading list" right after its title and author in its row's VoiceOver label, as in "Loose Pages, by Ines Okonkwo-Varga, In reading list, New, Plain Text", so it is in the same place on every row; in edit mode a selected row still begins "Selected", and the row has no VoiceOver value of its own. At the Reading List, Move Book Up, Move Book Down, and dragging rearrange the list, its Sort menu names its one order, Reading List Order, and an empty list says how to add a book; Remove from Library… and the Delete key still remove a book from the library there, so take a book off the list alone with Remove from Reading List. A book that leaves the library leaves the list too, one taken out with Remove from Library Only included, even when the next launch is what takes it out. At the Reading List, Open Book…, Import Folder…, and New from Text…, whether chosen in the Add to Library sheet or from their menus, put their books in the folder the window showed last, as anywhere else, and add them to the end of the reading list; VoiceOver says where the books themselves went, as in "Added to reading list: Moby-Dick. The book is in Essays/Sea.", calling the top of the library Library Root, as the folder pickers do, and says it after the import's own words, not over them. A ZIP archive's books join together, a duplicate joins once you keep both, and a book opened from Finder never joins. Replace on a duplicate gives the new copy the old one's place on the reading list, wherever you import it; at the Reading List, the new copy of a book that wasn't on the list joins its end, and VoiceOver says so. Above the list, When a book ends chooses what a book opened from the list does at its end: Play the book below, the default, Play the book above, or Stop (see [Reader windows](reader-windows.md)). Skip finished books, checked unless you clear it, passes over the books Books Finished counts, in the Stats tab of Settings: a book joins them when it is played or read to its end and doesn't start again, and stays when you read it again.
- Edit Mode selects several books at once to move or remove them, or to add them to the reading list or take them off it. The bar above the list counts the books selected, in the list or with edit mode's checks, as in "Edit mode, 3 of 12 books selected", counting only books the list shows, and the toolbar's Done counts them the same way in its hint. Select All becomes Deselect All once every book listed is selected, and is dimmed while no book is listed. In edit mode, the bar above the list offers Add to Reading List and Remove from Reading List beside Move, for the books selected: Add for those not in the list, Remove for those in it, and both for a selection holding each. VoiceOver hears how many books each acts on, as in "Add 3 books to the reading list", and each says what it did, as the context menu's commands do. With nothing selected, the bar shows the one the view suggests, dimmed: Remove from Reading List at the Reading List, and Add to Reading List elsewhere. At the Reading List, books you take off the list leave the selection too. Leave edit mode with the toolbar's Done, which VoiceOver calls Exit edit mode, or Edit Mode in the Library menu, Command-E; the bar has no Done of its own.
- A row's hint says what it does, never a gesture or a key, since VoiceOver, a braille display, and the keyboard each do it their own way: a folder's row says "Opens the folder.", and a book's "Opens the book.", or, in edit mode, "Selects this book." or "Deselects this book."
- The Move dialog puts the selected books in a folder chosen from its pop-up, or in one its New Folder fields make. New Folder… opens those fields with the keyboard in their name field, where VoiceOver lands. While they are shown, Return presses their Create, and Escape, like Cancel New Folder, closes them, keeps the folder chosen, and says so, as in "New Folder cancelled. Destination folder: Reports."; Create makes the folder and says so, with the new folder chosen, as in "Folder Q3 created. Destination folder: Reports/Q3."; once they close, Return presses Move again and Escape closes the dialog. Episodes and articles stay in their feeds' folders: their rows offer no Move to Folder… (Move to Library…, on a downloaded one's row, makes it a book of the library's own; see [Podcasts and article feeds](feeds.md)), and with only episodes and articles selected, the Library menu's Move to Folder… (Shift-Command-M) and the edit bar's Move open no Move dialog, while a selection holding books too moves only its books; either way VoiceOver says which stayed, a moment after the dialog has closed when there is one, as in "Left “Ep. 368” where it is: episodes and articles stay in their feeds; Move to Library… makes one a book of your library." A move, a folder's rename or move, or Delete Folder's Move Contents that fails keeps its sheet open with the reason, which VoiceOver hears once, and trying again clears that reason until the new attempt answers. Book Info, in a book's context menu, edits a plain text, Markdown, or HTML book's title and author (an EPUB's or an audiobook's metadata opens in an editor of its own, and an episode's or article's in its feed opens read-only; see [Podcasts and article feeds](feeds.md)): Save waits for a title of more than spaces, and drops the spaces typed around the title or the author. Command-I opens Book Info for the selected book and Feed Info for a feed's row, and, for a folder, which has no Info sheet, speaks the folder's full summary, as Speak Full Info does (below). With several rows selected it acts on the first in the list's order, in Edit Mode on the first book selected, and with none it does nothing.
- TextMouth records which of a book's details you typed yourself. When you save Book Info, or the metadata editor of an EPUB or an audiobook, each field whose value you changed is marked as edited by hand, in library.json and in the book's record: the title, the author (an audiobook's artist), an EPUB's publisher and publication date, and an audiobook's album, genre, and year. The next time you open Book Info, from the Library window or from a reader, VoiceOver says "edited by hand" after the label of each such field, as in "Book title, edited by hand"; in a reader, that includes a field you saved there a moment before. Saving changes, and marks, only the fields you changed in that editor since it opened. A field you leave as the editor showed it is neither saved nor marked, even where the editor showed what the book's file says, and even if another window, or the metadata refresh after an update, changed it while the editor was open: that change stays. The Book Info sheet of a plain text, Markdown, or HTML book trims the spaces around the title and the author as it saves, so a title or an author that differs from what the sheet showed only in those spaces counts as unchanged; the EPUB and audiobook editors save what you type as it is. While a book's file is only in the cloud, its editor shows empty each detail TextMouth doesn't know, such as an EPUB's publisher and date or an audiobook's album, genre, and year; a detail you leave empty there stays unknown, so the file's own values show once the book is downloaded. When you also check Also write to the library's copy of the EPUB file, the file takes the book's title, author, publisher, and date as the library has them at that moment, your changes included. A field once marked stays marked, even if you later type back what the file says. The metadata refresh after an update never replaces a field edited by hand (see library.json, under [Where TextMouth keeps your library](where-your-library-lives.md)).
- In a Library window, a letter pressed alone moves to the first book or folder whose name starts with it. That is the list's own letter navigation, and no shortcut takes such a key there, or in a sheet over a Library window, however the Shortcuts tab sets it. Shortcuts that are a letter alone, W, J, K, L, F, and B by default, work in reader windows only. Space is not a letter, so Play / Pause keeps it. A letter with Shift, Option, Command, or Control still runs its shortcut in a Library window, as a Shift-R you gave Release Media Controls does. Shift-J and Shift-L no longer fall back to the actions of J and L there, so the list takes them (see the Shortcuts tab, in [Settings](settings.md)). Speak Info and Speak Full Info had I and I twice until October 17, 2026; unless you changed their keys, they follow the new defaults, described next.
- Speak Info, Shift-Command-I or Library menu, Speak Info, speaks the selected row's brief summary in TextMouth's own voice, the voice and speed set in the Voice tab of Settings, as Where Am I? speaks a position in a reader, so it works with VoiceOver off too. A book's summary gives its title, its author unless none is known, its format, its folder or "Not in a folder", or, for a feed's episode or article, its feed, as in "In The Digital Antiquarian, a feed", its place in the reading list, for a book in it, in every view, as in "In reading list, 3 of 12", its progress and time left as its row says them, and "Unopened" for a book never opened, as in "Middlemarch. By George Eliot. EPUB. In Classics. In reading list, 3 of 12. 42 percent. 2 hours, 5 minutes remaining." A folder's gives its name, "Folder", its books, in it and in every folder inside it, with how many are unopened, and its feeds, when it holds any. A feed's gives its title, "Feed", "Unsubscribed" while you are unsubscribed from it, "Folder missing" when its folder is gone, its items counted as its row counts them (see Feeds in the library, under [Podcasts and article feeds](feeds.md)), and its last check, or, for a feed you unsubscribed from, since when it hasn't been checked, as in "Finish It!. Feed. Unsubscribed. 10 of 381 episodes listed. Not checked since October 9 at 3:05 PM." With nothing selected it says "Nothing is selected."
- Speak Full Info, Shift-Command-I pressed twice quickly or Library menu, Speak Full Info, speaks the selected row's full summary: the first Shift-Command-I starts the brief summary at once, and a second within the double-press time (see the Shortcuts tab, below) switches to the full one. A press of Shift-Command-I while a summary speaks stops it, as Speak Full Info does while the full one speaks, and Shift-Command-I on another row while a summary speaks speaks that row's summary instead, or, with nothing selected, says "Nothing is selected." However soon it follows the last summary, Shift-Command-I speaks the brief one: the three-second rule of earlier versions, under which a quick third press reached the full summary, is gone. Where Am I? works the same way in a reader, with W and W twice, Where Am I? Full Summary, which the Playback menu offers too, as does the reader toolbar's Where Am I? button among its actions in VoiceOver's Actions menu (VO-Command-Space): the book stays paused, with no second start sound, until the full summary ends. Play/Pause pressed while Where Am I? speaks, from the keyboard, the AirPods, or a media key, a Pause from the AirPods or a media key, and the book's sleep timer running out end the announcement without resuming the book, and so do the AirPods disconnecting, a recording starting, and another book starting while the book counts as playing, as it does while the announcement holds it paused or holds a Play for it (below); a book the announcement paused then stays paused as any pause leaves it: no time after it counts as listening, a sleep timer's countdown waits for Play, and an audiobook's Play/Pause button says Play. A Play from the AirPods, a media key, or Control Center while Where Am I? speaks waits for it: a book the announcement paused plays again as it ends, and a book paused or stopped before it starts once its end sound has played, with the play sound. Until the book plays again, it still counts as playing: a sleep timer running out, a Pause from the AirPods or their leaving, a recording or another book starting, or Play/Pause in that moment leaves it paused, and Where Am I? pressed in the moment after the announcement has ended, before the book plays again, keeps it paused until the new announcement ends, while a skip in that moment resumes it at once. Over a book paused or stopped before the announcement began, with no Play pressed, the announcement goes on when another book starts. Release Media Controls ends the announcement with the book, so the book stays stopped and the AirPods stay released, and so does anything else that stops the book, as a chapter that can't be downloaded or played does. A jump while Where Am I? speaks, by Next Heading or Previous Heading, a heading, bookmark, or search result picked from its list, Go to a percent or a time, or Return to previous position, ends the announcement as a skip does: a book it paused plays on from where the jump lands, and a book a Play was pressed for starts there. With Auto-play on navigate, a heading, bookmark, or search result picked from its list also plays a book paused or stopped before the announcement, from where the jump lands. Should the speech engine cancel the announcement before it ends, whatever waited for it starts as the announcement's end would have started it: a book you pressed Play for during the announcement, the one it paused included; a chapter whose files arrived during it; and a book waiting for its chapter's speech, at once or as soon as the speech is ready. With no Play pressed, the book the announcement paused stays paused, and Play/Pause resumes it. Play/Pause during Where Am I? also pauses, without the pause sound, a book waiting to start, as it does without the announcement: one waiting for its chapter's speech, for a chapter's files to download, or for the library to finish moving it. A Play pressed while Where Am I?'s end sound plays changes nothing: the book, or a chapter whose files arrived during the announcement, starts once the end sound has played, with no play sound. If the sound output changes while Where Am I? speaks over a book it paused, as when AirPods connect, or the library moves that audiobook's files meanwhile, the book plays on afresh from where it paused once the announcement ends, on the new output or from the files' new place; a text book keeps speaking in the voice. Edit Text taken while Where Am I? speaks over a playing book ends the announcement, and the book plays on in the edited text from its place. Setting a sleep timer while Where Am I? speaks lets the announcement finish and plays the book as it ends. In a library in the cloud, a chapter whose files arrive while Where Am I? speaks plays once the announcement has ended, even if the library moves the book meanwhile, from the book's new place. A book's full summary adds when it was added and last opened, its bookmarks, its file size, unless its files are in the cloud, which are never downloaded to measure them, its cloud note and whether it is kept on this Mac, and whether a reader window has it open; a folder's adds its subfolders and the time left in all its books; and a feed's adds its folder and its address. Shift-Command-I has Command in it, so it works from the search field, or any text field, as Command-I does. The Shortcuts tab lists Speak Info and Speak Full Info under Information, after Where Am I? and Where Am I? Full Summary, and leaves either without a key while you have given its key to another action.
- A book's context menu, and its actions in VoiceOver's Actions menu (VO-Command-Space), include Show in Finder, which selects the book's package in Finder. In a library in the cloud they also offer Download Now, Remove Download, and Keep on This Mac (see [Keeping your library in the cloud](cloud-library.md)). An audiobook's also offer Edit Audio… (see [Editing audio](editing-audio.md)) and Transcribe Audio…, and a transcribed audiobook's Clean Up Transcript (Experimental)… and Delete Transcript… (see [Transcribing an audiobook](transcribing.md)); a feed's episode, which can't be edited, offers neither Edit Audio… nor Clean Up Transcript (Experimental)….
- File menu, Export… exports the books selected in the Library window, and a book's context menu (VO-Shift-M) has Export… too, or Export 3 Books… for a selection of three (see [Exporting books](exporting-books.md)); with no book selected, VoiceOver says "No books are selected." With neither a Library window nor a book's window in front, as when only Settings is open, File menu, Export… says so instead: "No Library window or book is open, so there is nothing to export." or "To export, switch to a Library window or a book's window, then choose Export again." A text book's context menu, and a transcribed audiobook's, also has Edit Text in Default Editor and Edit Text With…, unless several books are selected or the book is a feed's episode or article (see [Editing a book's text](editing-book-text.md)). These commands aren't among the row's actions in VoiceOver's Actions menu.
- A summary line gives each location's book count and its listening time remaining at the current speed, and, in a library in the cloud, how many of its books are in the cloud and how many are kept on this Mac. The count never counts a feed's episodes and articles as books: where the Feeds section lists feeds, it names them beside the books, as in "743 books, 2 feeds", or "2 feeds" where there is no book; in Recently Opened and the Reading List, which list episodes and articles beside books, it counts each kind, as in "9 books, 1 article", as the list's heading does, "Books (9), Articles (1)"; and in a feed's folder it counts the feed's episodes instead (see Feeds in the library, under [Podcasts and article feeds](feeds.md)). VoiceOver hears the same words entering a folder, as in "Library, 743 books, 2 feeds", and in a folder's row, as in "Podcasts, 3 books, 2 feeds". Storage settings' Library Statistics count the books, then the feeds, where there are any, the folders, and the books kept in packages, and Use This Library's confirmation counts the library in use the same way.
- The Continue button names the book last opened, as in "Continue: Emma", and opens it. It shows that book's time left as a row does, as in "16:00 left", and VoiceOver says it as a row does, as in "Continue listening to Emma, 16 minutes remaining"; for a finished book, which has no time left, it shows and says none, as in "Continue listening to Emma".
- The toolbar's buttons for adding and for settings:
  - Add to Library, a plus button between Up One Level, where that shows, and the edit mode button, opens the sheet of ways to add to the library (see [Adding books](adding-books.md)). On October 17, 2026 it took the place of the Import, New from Text, and Add Feed buttons.
  - Feed Settings or Folder Settings, between New Folder and the Sort menu, shows only in a folder of the Folders category: never at the top of the library, and in no other category. A feed's folder, the folder that lists the feed's episodes or articles, gets Feed Settings, even when it also holds books of your own; any other folder gets Folder Settings.
    - Feed Settings opens the feed's Feed Info, the sheet that Command-I opens on the feed's row (see [Podcasts and article feeds](feeds.md)). VoiceOver calls the button "Feed settings for" and the feed's title, as in "Feed settings for Planet Money", and its hint is "Opens the settings of this feed: where its downloads go, what it lists and downloads, and what happens when an episode ends".
    - Folder Settings opens the Folder Settings sheet (below). VoiceOver calls the button "Folder settings for" and the folder's name, as in "Folder settings for Classics", and its hint is "Opens the settings of this folder: what it holds, and what happens when one of its books ends".
  - Folder or Feed Settings, in the Library menu after Remove from Reading List and among the Library actions of the Shortcuts tab of Settings, does what the button does for the folder the window shows. It has no key until you give it one. Where the window shows no folder, because it is at the top of the library or in another category, VoiceOver says "Open a folder first to see its settings".
- The Folder Settings sheet shows a plain folder's facts and how listening goes on from one of its books to another:
  - Its title is "Folder Settings", and the folder's name is its heading. Under the heading are read-only rows. Each is one element that VoiceOver says as its label, a comma, and its value, and its value can be selected and copied: "Location", the path of the folder that holds this one, or "Library Root" at the top of the library; "Books", the books in the folder and in every folder inside it, with how many are unopened, as in "12 books, 3 unopened"; "Subfolders" and "Feeds", each only when the folder has any; and "Time remaining", only when it is known, as in "14 hours, 3 minutes remaining in total".
  - Under a heading, "Listening", are two controls, each saved as you choose it. The pop-up button "When a book ends" offers "Use the global setting (…)", which names the Playback tab's When book ends choice, as in "Use the global setting (Continue to Next Book)", then "Play the book below", "Play the book above", and "Stop". Its hint is "What happens when one of this folder's books ends: play the book below it or the one above it in the folder, stop, or follow the global setting". The checkbox "Skip finished books", checked unless you clear it, has the hint "When listening goes on to another book, pass over the books already finished". What they do is under When a book ends, in [Reader windows](reader-windows.md). A folder's choices apply to the books directly in it, never to those in the folders inside it.
  - Done closes the sheet, and so do Return and Escape, since nothing in the sheet takes typing. If another window deletes the folder while the sheet is open, the sheet says "This folder is no longer in the library." in place of the folder.
- If a file cannot be saved (a full disk or a missing volume, for example), a banner in the Library window says what is unsaved, with Retry and Dismiss buttons. Quitting while something is unsaved asks first.
- A Library window showing a folder that another window deletes, as Delete Folder… or Delete Feed… can, goes to the nearest folder above it still in the library, and one showing a folder another window renames or moves follows it to its new place. Nothing moves while the library's index is being recovered.
- An audiobook of tracks' row offers Edit Manifest in Default Editor and Edit Manifest With… in its context menu, after Edit Text's commands (see [The audiobook manifest](audiobook-manifest.md#editing-an-imported-books-manifest)).

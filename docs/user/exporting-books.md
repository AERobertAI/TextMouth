# Exporting books

Part of [TextMouth's documentation](../../README.md).

- The Export dialog lists what the books hold: a checkbox for each kind, labelled with its size and with its number of files when there are several, or, for several books, with how many of them hold it, as in "Original file, 1.2 MB", "Audio, 12 files, 340 MB", or "Audio, 2 books, 680 MB". The kinds are Audio, an audiobook's file or its tracks; Original file, a text book's own file (an .rtfd, which is a folder, is copied whole, and its size is that of the files inside it) or, for an audiobook whose import kept the originals of the audio it converted (Keep originals of converted audio, under [Settings](settings.md)), those files as they were before: one file under its own name, or, for a book of tracks, a folder named like "Moby-Dick - Original Files", each original under its path inside the book's folder of tracks; Text as Markdown, the text TextMouth reads, with a line marking each chapter (the Convert to menu, below, can make it HTML, RTF, or a Word document instead); Text as plain text, each chapter's words under its title, before any substitution rules; Original recording, a recording as it was made, before any edits; Original audio (before edits), an edited audiobook's audio as it was before its first edit, which TextMouth keeps while the Original audio setting does: one file named after the book, as in "Moby-Dick - Original Audio.mp3", or, for a book of tracks, the edited tracks' originals in a folder of that name; and Transcript, its transcript.json and, for an audiobook, the transcript's text as Markdown. Kinds that none of the books hold aren't listed. VoiceOver starts on the first checkbox, and the first kind that can be exported is checked.
- The files go to your Documents folder, or to the folder you last exported to since TextMouth opened. Choose Folder… chooses another, and its New Folder button makes one; TextMouth's own data directory is refused. One book's items go straight into the folder, except its tracks, or a DAISY book's loose files, which go into a folder named after the book: tracks are numbered in the order the book plays them and named for their chapters, as in "01 - The Harbour.mp3". Several books get a folder each. A name already in use gets a number, as in "Moby-Dick - Text 2.md", so nothing is ever replaced. Each file, whether copied, plain text, or converted, is made first in a scratch folder, on the same disk as the folder you chose when the Mac provides one there, and moved into that folder only once it is whole, never over a file that is already there. So an export never replaces or removes a file that was already in the folder, and the folder never holds a half-written file, even after Stop or a failure.
- Return presses Export, and Escape presses Cancel, or Stop while the export runs, which ends the export: the files finished so far stay in the folder, and the file being made is not kept. A progress bar says how far it has got, as in "Exporting 3 of 40 items…"; it counts finished files, so it does not move while one long book is converted. At the end VoiceOver says how it went, as in "Exported 3 items to Documents.", and the dialog closes, unless the export was stopped or left something out: then it stays open, saying what couldn't be exported and why, and Cancel becomes Close.
- Nothing is downloaded. In a library in the cloud, a kind whose files are only in the cloud says "in the cloud" and can't be checked, and the books it leaves out are named, as in "Moby-Dick isn't downloaded. Download it first: select it in the library, then choose Download Now."

## Converting a book's text

- While Text as Markdown is checked, a pop-up named "Convert to" sits beside it, and VoiceOver reaches it right after the checkbox. Its label is "Convert to", its value is the choice made, and its hint is that choice's hint. The choices are Markdown, HTML, RTF, and "Word 97-2003 (.doc)", and their hints are:
  - Markdown: "The book's text as Markdown, the file TextMouth reads it from, as it is."
  - HTML: "A web page of the book's text, with a contents list linking each heading."
  - RTF: "Rich text, with each heading at its outline level, for Word, Pages, and TextEdit."
  - Word 97-2003 (.doc): "Word 97-2003 document. Its headings are plain text, so Word's navigation pane does not list them."
- Every Export dialog starts on Markdown, so an export made as before gives the same file under the same name, and a dialog keeps the choice made in it until it closes. Only a text book's Text as Markdown checkbox has the menu: an audiobook's Transcript is exported as it is.
- While HTML, RTF, or Word is chosen, the checkbox is named for the choice, as in "Text as HTML" or "Text as Word 97-2003 (.doc)", and "Text as HTML, 2 books" for several books. It then gives no size, since a converted file's size is known only once it is written; with Markdown chosen it keeps its size, as before. Its hint is "The book's text as HTML, made from the Markdown TextMouth reads it from.", with RTF or Word 97-2003 (.doc) in place of HTML.
- Each book gets its own file, named like the Markdown's but with the format's ending, as in "Moby-Dick - Text.html", "Moby-Dick - Text.rtf", or "Moby-Dick - Text.doc", and numbered when the name is in use, as in "Moby-Dick - Text 2.html".
- TextMouth converts the books one at a time, and the dialog's progress bar and Stop work as in any export. A book that cannot be converted is named in the sentence VoiceOver says at the end, with why, and the other books still export. When Word's writer cannot make a book, the sentence is "Couldn't export Moby-Dick - Text.doc: The book's text could not be made into a Word 97-2003 document."

## What a converted file holds

- The text is the book's content.md, the Markdown TextMouth reads, with any edits you made in Edit Text (see [Editing a book's text](editing-book-text.md)), before any substitution rules. Markdown stays the base: HTML, RTF, and Word 97-2003 are each written from it, and the Markdown choice is content.md as it is.
- HTML, RTF, and Word 97-2003 all leave out content.md's chapter-marker lines, its navigation annotations, and any raw HTML, and a picture becomes its alternative text.
- A chapter with no heading of its own gets its title as a level-1 heading, as the reader's heading list shows it. The book's title becomes a level-1 heading, written first, only when the text has no level-1 heading.
- Each file carries the book's title, and its author when the library has one. In HTML and RTF, only http, https, and mailto addresses become links; any other link is plain text.
- HTML is a web page (XHTML), and it carries the book's language when the book has one. When the text has headings, the page has a contents list, a navigation landmark named "Contents", that links each heading; the list leaves out the book's own title heading.
- RTF headings are bold and larger, from 22 point at level 1 down to 13 point at level 6, and carry outline levels, so TextMouth reads them back as headings at the same levels. A list is a run of paragraphs, each starting with a bullet or a number and a tab. A table of more than 63 columns becomes a paragraph for each row, its cells apart by tabs.
- Word 97-2003 (.doc) is made by Apple's writer from TextMouth's RTF, so it holds the same text. Its headings are larger and bold but plain text, so Word's navigation pane does not list them. It loses six rare characters that the RTF keeps: the bidirectional embedding and override controls U+202A to U+202E, and U+FFFD, which becomes "?".

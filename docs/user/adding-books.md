# Adding books

Part of [TextMouth's documentation](../../README.md).

- File menu, Open Book… (Command-O) imports the files you choose. Opening a supported file from Finder imports it and opens it.
- File menu, New from Text… makes a book from text you type or paste. Its key, Shift-Command-T, works in Library windows, and with no window open, when it opens New from Text… in a new Library window. In a reader window the same key opens or closes the Sleep Timer sheet (Show Sleep Timer); there, and in Settings, the New Recording window, and an audio editor's window, File > New from Text… is dimmed and shows no key, so choose it from a Library window. Either action can have another key, or work in another kind of window, from the Shortcuts tab of Settings (see Works in, under the Shortcuts tab).
- File menu, New Recording… (Option-Command-N), also in the Library menu, records from a microphone into a new audiobook (see [Recording from a microphone](recording.md)).
- Library menu, Import DAISY Folder… (Shift-Command-O, in a Library window) imports DAISY books kept as loose files, one folder per book.
- Library menu, Add Feed… (Shift-Command-F, in a Library window), or the Library window's Add Feed button, subscribes to a podcast or article feed (see [Podcasts and article feeds](feeds.md)).
- A ZIP of several books imports each of them, and TextMouth offers to create a folder for them. The progress overlay's Cancel button stops a ZIP import after the book in progress.
- While books import, the import overlay in the Library window shows how far the import has got, and VoiceOver reads all of it there. For a ZIP archive it first counts the items and bytes extracted, as in "Extracting “Library Export.zip”: 120 of 300 items, 1.2 GB of 3.4 GB...", then the books processed, as in "2 of 100 books processed", with the book under way, by its name in the archive, and the step it is at, as in "Book 3 of 100: “Moby Dick.epub”, reading its text"; a single file, or a ZIP holding one book, shows its name and its step the same way, as do a TextMouth package opened from the Finder, from "checking the package" on, and a book made with New from Text, by the title you typed. A package's line says "copying it into the library" while it copies, and a recording saved from the New Recording window is named by its title the same way, its line going quietly once the save ends, since its window says how the save ended. The count's noun agrees with the total, as in "0 of 1 book processed", as it does in the overlay of a text cache update or of Redo Text Extraction, as in "0 of 1 book extracted". A ZIP holding one audiobook also counts the items and bytes extracted while it extracts, as in "“Harbor Talks.zip”, extracting the archive: 12 of 30 items, 120 MB of 340 MB". Once a book of several is done, the overlay gives the time left, as in "About 4 minutes left" or "Less than a minute left": it weighs each book still to come by its size where that tells its time, as an EPUB's, PDF's, Word document's, or text file's does, so a large book still to come counts for more, while an audiobook's file or a DAISY book counts at the average time such books took. When more imports wait behind the one shown, the overlay says how many, as in "2 more imports waiting", until Cancel is pressed. Once a book has taken 10 seconds, the overlay says for how long, as in "1 minute, 5 seconds on this book", in steps of 5 seconds, so a stuck book shows as a time growing on one step. For an import that runs 10 seconds or more, VoiceOver also hears, wherever you are, each quarter of a ZIP's books, as in "Importing “Library Export.zip”: 25 of 100 books processed, about 4 minutes left.", and how it ended, as in "Finished importing “Library Export.zip”: 97 books imported, 2 skipped as duplicates, 1 failed." A ZIP import that brings no new book, and in which nothing failed, says what it found in the Library window's alert, titled Nothing Imported, however quickly it ends: "No new books in “Library Export.zip”: all 24 were already in your library." ("both" for two, and "its one book" for one), or, for an archive holding no book TextMouth reads, what it holds instead, most files first, as in "No books were found in “Radio.zip”. It holds 176 .wma files, which TextMouth does not import." Up to three kinds are named, the rest counted as other files. The alert waits on screen, and VoiceOver reads it as it appears, so it is never missed as an announcement made while you were in another app could be. One with a failure says so in its alert instead. Cancel says at once "Cancelling after this book...", or "Cancelling..." before the first book, and the alert of a cancelled import says where it stopped. Library menu, Speak Import Progress has VoiceOver speak the overlay's lines on request, or say "No import is under way."; give it a key in the Shortcuts tab of Settings, under Information, to use it in every window but an audio editor's, a reader's included (see Works in, under the Shortcuts tab).
- When a book's content is already in the library, TextMouth asks whether to keep both, replace the existing book, or cancel. A feed's episode or article holding the same file doesn't count.
- Storage settings decide what happens to the original file after an import: keep it (the default), delete it, or ask each time.
- With Offer to transcribe after importing an audiobook on, in the Playback tab of Settings, TextMouth asks after each audiobook it imports, on a Mac that can transcribe, whether to transcribe it, after that import's other questions (see [Transcribing an audiobook](transcribing.md)).
- These questions wait their turn. They are asked one at a time, in the order they arose, in the Library window where the import started, or in another Library window if that one has closed. When there is more than one, each title gives its place, as in "Duplicate Book Found, 2 of 5". Return chooses Keep Both, Create Folder, or Transcribe, and Escape chooses Cancel, Keep, No Thanks, or Not Now; Replace Existing and deleting an original file are never on a key. A question that appears while you are working in another window, such as a reader, waits in its Library window without taking focus or speaking.
- A book opened from Finder opens once it is in the library and its questions are answered.
- The progress overlay's Cancel button also withdraws the questions of the imports started before it was pressed, those waiting and any still to come: a duplicate's new copy is discarded, an original file is kept, a ZIP's books stay where they are, and an offer to transcribe is dropped.

## A manifest's title and author
<!-- id: manifest-title-author; keys: manifest.json, book title, book author, blank title, ZIP name, audiobook folder; src: TextMouth/Parsers/AudioBookParser.swift, TextMouth/Parsers/AudioManifest.swift, TextMouth/Services/FileImportService.swift -->

A manifest's title and author (FR17): publishTracks and AudioBookParser take them through AudioManifest.bookTitle and bookAuthor, which read one that is empty or only whitespace as none, so the name of the ZIP or folder, or Unknown, stands as for a missing one.
The manifest's stored title and author keep every byte.

## Audio the import converts
<!-- id: audio-import-converts; keys: convert audio, Ogg, MP2, AC-3, afinfo codec, sniffer, ZIP of tracks, feed episode; src: TextMouth/Services/FileImportService+AudioConversion.swift, TextMouth/Services/FileImportService.swift, TextMouth/Services/ImportAudioConverter.swift, TextMouth/Services/BookManifestEditing.swift, TextMouth/Services/ImportFailure.swift, TextMouth/Services/AudioFileInfo.swift, TextMouth/Parsers/AudioContentSniffer.swift -->

Audio the import converts (B06, FMT09): FileImportService.publishReadableBook converts a staged book's audio first (convertImportedAudio(of:in:keepingOriginals:run:), in FileImportService+AudioConversion.swift; step .convertingImportedAudio(done:of:)), before anything reads it as a book, so a ZIP of tracks, a folder, a single file, a playlist, and a feed's episode are converted in one place, each converted file renamed in the manifest through BookManifestFile.change.
ImportAudioConverter.tracksNeedingConversion(in:) (a folder) and needsConversion(among:) (files) choose the tracks, by what each holds: verdict(for:) takes the extension (convertedExtensions: oggExtensions and coreAudioExtensions) and then AudioContentSniffer.kind(of:), which reads a file's first 64 KB by hand with no Apple audio API.
Ogg, AC-3 and E-AC-3, CAF, AIFC, AU, Wave64, AMR, 3GPP audio, and MPEG layers I and II convert.
WAVE (RIFF, RF64, BW64), AIFF, FLAC, MP3, and ADTS AAC are left.
MPEG-4, QuickTime, and anything unrecognized go to afinfo, whose codec decides (playsAsIs(formatID:fileType:): AAC, Apple Lossless, and MP3 in them stay).
So an Ogg file named .m4a, or an MP2 feed episode named .mp3, is converted.

## Reading a source's audio facts
<!-- id: reading-source-audio-facts; keys: afinfo, afconvert, AAC, Apple Lossless, bit rate, bit depth, SourceInfo, failed Ogg book; src: TextMouth/Services/ImportAudioConverter.swift, TextMouth/Services/OggHeaderReader.swift, TextMouth/Services/AudioFileInfo.swift, TextMouth/Platform/macOS/Services/WatchedProcess.swift, TextMouth/Parsers/AudioMediaProbe.swift, TextMouth/Parsers/AudioContentSniffer.swift, TextMouth/Services/AudioEditing/AudioEditComposition.swift, TextMouth/Services/TranscriptionEngine.swift, TextMouth/Services/TranscriptionService.swift, TextMouth/Services/AudioPlaybackService.swift, TextMouth/ViewModels/OggConversionProgress.swift, TextMouth/ViewModels/LibraryViewModel+OggConversion.swift -->

ImportAudioConverter reads a source's facts from OggHeaderReader for Ogg (Vorbis, Opus, or FLAC), and from AudioFileInfo for the rest: afinfo -x -r, run by WatchedProcess.runCapturingOutput, gives the container, codec, channels, sample rate, bit depth, length, and whether it names a channel layout.
No Apple audio API opens the source in TextMouth's process. plan(for:info:) is leaveAsItIs, convertToAAC, or convertToAppleLossless when the codec keeps every bit (SourceInfo.isLossless: lpcm, alac, flac). target(for:bytes:) gives AAC the source's average bit rate (bytes × 8 ÷ duration) rounded up to the next standard rate (bitRate(averaging:channels:accepted:), 64 to 192 kbit/s for stereo, half for mono) at its own sample rate where AAC takes it (sampleRate(for:)), and Apple Lossless the smallest of 16, 20, 24, or 32 bits that holds the source's samples (24 when the depth is unknown or the samples are floating-point). afconvertArguments(from:to:info:target:) never passes -c, since afconvert refuses it for AAC above stereo.
AudioMediaProbe, AudioEditBase.load, and the transcriber refuse every format the import converts by ImportAudioConverter.isNeverDecodedInApp(_:), a converted extension other than TextMouth's own CAF or a file that begins with OggS (AudioContentSniffer.isOgg(at:)).
AudioPlaybackService.metadataAsset(for:) asks isConvertedAtImport, by extension alone, since an import reads a source before it converts it.
OggConversionProgress.markFailed keeps a failed book from being tried again before the next launch (B09).

## Probing an audio file's duration
<!-- id: probing-audio-file-duration; keys: audio duration, unplayable audio, AVAssetReader, decode check, header length, hung read, Swift concurrency pool; src: TextMouth/Parsers/AudioMediaProbe.swift, TextMouth/Parsers/AudioBookParser.swift, TextMouth/Services/BookContentAnalysisService.swift, TextMouth/Services/ImportAudioConverter.swift -->

AudioMediaProbe.duration(of:) (Parsers/AudioMediaProbe.swift, through AudioMediaProber for AudioBookParser and BookContentAnalysisService, and directly for ImportAudioConverter) tells how long an audio file plays or why it cannot be played, and decodes the opening and the last second of its track to confirm its header.
Since 0.4.5 that decoding check runs on a concurrent dispatch queue of its own, never in Swift's concurrency pool, where a read that never returned (AVAssetReaderOutput.copyNextSampleBuffer() on a GitHub runner) held one of its few threads for good.
The probe waits for it 60 seconds at most (decodeDeadline): then the check's readers are told to stop (AVAssetReader.cancelReading()) and the file passes on its header's length.
The deadline holds the check's job weakly, so a check that answers frees the file's asset and readers at once.

## Audio of more than two channels
<!-- id: audio-more-than-two-channels; keys: surround, 5.1, downmix, stereo, channel layout, centre channel, afconvert --mix, disk space; src: TextMouth/Services/ImportAudioConverter.swift -->

Audio of more than two channels (maximumChannels is 2) takes two steps (write(_:to:info:target:using:)):
- downmixArguments writes a hidden stereo CAF (".<UUID>.audio-downmix.caf", linear PCM, 16 bits for AAC and the lossless depth, 24 for 20, with -c 2 --mix, because without --mix afconvert drops channels by position and a PCM source's centre came out silent), and
- afconvertArguments encodes that file, which is removed as soon as the second step ends.

Before the first step the volume's free space must hold the PCM file and a 512 MB reserve (downmixBytesNeeded(duration:target:), Failure.notEnoughSpace), and a source of more than two channels that names no layout is refused (Failure.unlabelledChannels).
Apple's normalized mix puts the centre in both channels about 10.7 dB down for PCM and 13.7 dB down for AC-3, measured on macOS 26.3.1.

## What watches a conversion
<!-- id: what-watches-conversion; keys: watchdog, time limit, output cap, stall, afconvert limits, afinfo limits, lying header, converted file check; src: TextMouth/Services/ImportAudioConverter.swift, TextMouth/Services/AudioFileInfo.swift, TextMouth/Parsers/AudioMediaProbe.swift, TextMouth/Platform/macOS/Services/WatchedProcess.swift -->

What watches a conversion: afconvert gets 60 seconds plus a tenth of the track's length, 1 GiB, a stall allowance of 20 seconds, the default processor-time allowance, and an output cap of four times what it should write and 16 MB more (outputCap(of:duration:target:); the expected output is the AAC rate times the length, 320 kbit/s where the encoder chooses, or for Apple Lossless and the downmix's PCM the length times rate, channels, and bytes a sample), set as Limits.maximumOutputBytes.
AudioFileInfo.read(_:using:) gets 30 seconds plus one for each 20 MB, 512 MiB, and a cap of 1 MiB on what afinfo prints, and believes a length only up to a year and only as far as the file's bits at the codec's lowest bit rate allow (isPlausible(inFileOfBytes:), logged as AUDIO_INFO_IMPLAUSIBLE; a 136 KB CAF once claimed 25 billion seconds), so a lying header cannot lift the time limit or the cap; a file it cannot read is Failure.unreadable.
AUDIO_CONVERSION_KILLED (in place of OGG_CONVERSION_KILLED) and AUDIO_INFO_KILLED are storage events.
The converted file is written under ".<UUID>.audio-conversion.m4a", checked by AudioMediaProbe (it plays, and lasts as long as its source to within allowedLengthError(for:), a second and half a percent), and only then named.

## Kept originals
<!-- id: kept-originals; keys: Keep Original, keep original audio, setting, hidden folder, Export original file, converted audio, feed episode; src: TextMouth/Services/ConfigService.swift, TextMouth/Services/FileImportService+AudioConversion.swift, TextMouth/Services/ImportAudioConverter.swift, TextMouth/Services/FileImportService+Packages.swift, TextMouth/Services/BookExportService.swift, TextMouth/Models/ConvertedOriginalWording.swift -->

Kept originals: with the setting on (ConfigService's keepsOriginalOfConvertedAudio, read by keepsOriginalsOfConvertedAudio(feedLink:), and never for a feed's episode), convertImportedAudio moves each source into the package's hidden .convertedOriginals folder (ImportAudioConverter.keepSources(of:from:inPackage:): under its path from the book's folder of tracks, or by its own name for a single file) in place of removing it (removeSources(of:)).
The folder is hidden so that every track scan passes it by and FileImportService.isPackageContentName refuses it; a kept Ogg file is never opened, and BookExportService.convertedOriginalItem copies the files out as Export's Original file.
ConvertedOriginalWording holds the setting's words.

## Package track scans
<!-- id: package-track-scans; keys: TrackScan, track scan, packageTrackExtensions, stray audio file, chapter count, Ogg books, AIFC, own CAF; src: TextMouth/Parsers/AudioBookParser.swift, TextMouth/Models/Book.swift, TextMouth/Services/ImportAudioConverter.swift -->

Package track scans: AudioBookParser.audioFiles(in:scan:) takes a TrackScan.
The import's scans (.importing) take every audio format (BookFormat.audio.fileExtensions, which ends with coreAudioExtensions), since they run before the conversion.
A package's scans (.package: loading the reader, re-analysis, a manifest edit, the library's checks) take BookFormat.packageTrackExtensions, which leaves out the formats the import converts (coreAudioExtensions), so a stray .aifc, .au, or .ac3 left in a package is neither played nor counted as a chapter; Ogg stays, since the library converts the Ogg books it holds and that conversion needs their tracks found, and TextMouth's own CAF is taken by its name and place (isOwnCAF(atPath:)).

## Playlists
<!-- id: playlists; keys: playlist import, .m3u, m3u8, folder book, duplicate playlist, skipped entries, Book Imported alert, streaming playlist; src: TextMouth/Parsers/M3UPlaylist.swift, TextMouth/Models/PlaylistImportWording.swift, TextMouth/Services/FileImportService.swift, TextMouth/Services/BookManifestEditing.swift, TextMouth/Parsers/AudioManifest.swift, TextMouth/Parsers/TextFileDecoder.swift, TextMouth/Models/ImportProgressWording.swift, TextMouth/ViewModels/LibraryViewModel+Import.swift -->

Playlists (FMT10): importFileWithReport sends an M3U or M3U8 file (M3UPlaylist.isPlaylist, by extension) to importPlaylistWithReport, which builds a folder book through publishTracks as importAudioFolderWithReport does.
M3UPlaylist.read(at:) takes at most 4 MiB (an .m3u8 as UTF-8, an .m3u through TextFileDecoder) and parse reads #PLAYLIST, #EXTINF, and #EXT-X- lines; a stream is PlaylistImportError.streaming, and a list of only web addresses PlaylistImportError.onlyWebAddresses. resolve(inFolder:) uses only a file that realpath(3) puts strictly inside the playlist's own folder, and skips a web address, a Windows drive, a path outside, a missing entry, a folder, a file that is not one of BookFormat.audio's extensions, anything hidden or not a regular file, and a repeat (distinctTracks(of:) counts a second spelling of one file as a repeat), each as a Skipped with a SkipReason whose words the notice quotes; with no track left it throws PlaylistImportError.noTrack.
Each track is copied to the same path in the staged audio folder, with an AudioManifest built in memory from the playlist's order and titles and written there (BookManifestFile.encoded), so the manifest check and the conversion treat the book as any folder of tracks; the book is known by folderHash over the tracks' paths and the playlist's own file name, each with the MD5 of its bytes, so the same playlist imported twice is a duplicate.
ImportedBook.isFromFolder is set, so mayDeleteOriginal is false, and ImportedBook.notice holds PlaylistImportWording.notice(playlistName:skipped:) (at most 10 entries named within 600 characters, each location at most 60 characters, a file name of more than 40 shortened in its middle), which ImportedBook.announcement(warning:) joins to the warning; the library presents it under ImportProgressWording.bookImportedTitle ("Book Imported", where a failure's alert says "Error") and does not open the book.

## OggHeaderReader
<!-- id: oggheaderreader; keys: Ogg header, granulepos, chained Ogg, multiplexed stream, Ogg tags, Ogg duration, page CRC, cover art; src: TextMouth/Services/OggHeaderReader.swift, TextMouth/Services/AudioPlaybackService.swift -->

OggHeaderReader (Services/OggHeaderReader.swift, REV17a) reads an Ogg file's codec (Vorbis, Opus, or, since FMT09, FLAC), channels, sample rate, bit depth (FLAC), length, and tags from the file's own bytes.
Ogg FLAC's first packet (identifyFLAC) is the mapping header, "fLaC", and the STREAMINFO block, which gives the rate, channels, bits a sample, and total samples; the length is the last granule position, refused when STREAMINFO's total differs from it by more than a second; its tags are the VORBIS_COMMENT block among the header packets (flacTags). read(at:) takes the first 256 KB (headLength) and the last 70,000 bytes (tailLength) and hands them to parse(head:tail:), which is pure and bounded whatever the bytes are: a page counts only when it lies wholly inside the bytes and its CRC-32 checks (crc(of:)), so a stray "OggS" in audio data costs nothing, and at most 256 rejected candidates are tried in the tail.
It takes the identification packet of the Vorbis, Opus, or FLAC stream among the leading start-of-stream pages (audioStream(in:): a multiplexed file begins with one such page for each stream, and an Ogg Skeleton stream's fishead may come first, so the walk goes on while pages have the start flag, a page that fails its checks ends it, and the first serial whose first packet identify accepts is the stream; Speex, Theora, or an unknown codec gives nil), the length from the last page of that same stream in the tail (a page of another stream, as in a multiplexed file, is passed over, so a chained file whose tail holds only another stream's pages gives nil) less the granule position the stream starts at (StreamStart.startOffset: 0 for a stream that begins at the start of its recording, more for one cut from a longer stream, as a live broadcast joined an hour in), and the tags from its comment packet (title; artist, else performer; album; genre; date; a comment packet over 256 KB, cover art say, gives empty tags).
A length over a year (maximumDuration) gives nil, so no later Int(seconds) can overflow, and Opus always reports 48,000 Hz.
The start offset is found as libvorbisfile and opusfile find a stream's first sample (startOffset(of:codec:)): lead(of:headerCount:in:) gathers the stream's packets from its first page through its first audio page, the first page after the header packets (3 for Vorbis, 2 for Opus) that completes an audio packet and has a granule position of 0 or more, passing over up to maxAudioPagesWithoutGranule (16) pages that complete one without a granule and stopping, keeping what it has, at the first page that fails its checks; the offset is that page's granule less the samples its packets produce, never below 0 (Opus: each packet's frames from its TOC byte, RFC 6716, a packet over maxOpusPacketSamples, 5,760, being invalid; Vorbis: a quarter of each packet's block size plus a quarter of the previous packet's, the first packet giving none, from the identification packet's block sizes and the setup packet's modes).
It is 0 when anything cannot be read, and an offset past the last granule is ignored. streamStartOffset(inHead:) gives tests the offset.
The metadata readers use it too, through AudioPlaybackService.metadataAsset(for:) ([media playback](media-playback.md)).

## WatchedProcess
<!-- id: watchedprocess; keys: child process, watchdog, ulimit, process timeout, reaper, kill children, afconvert, textutil; src: TextMouth/Platform/macOS/Services/WatchedProcess.swift, TextMouth/Platform/iOS/Services/WatchedProcess+iOS.swift, TextMouth/Models/CountWording.swift, TextMouth/Services/PlaybackMemoryGuard.swift, TextMouth/Platform/macOS/App/AppDelegate.swift -->

WatchedProcess starts a tool as /bin/sh, which sets the kernel's processor-time limit (ulimit -t, from Limits.effectiveMaximumCPUSeconds: maximumCPUSeconds, else four times maximumSeconds) and then replaces itself with the tool (exec), so the pid it watches, measures, and kills is the tool's own; a child the kernel ends at that limit (SIGXCPU) is reported as KillReason.usedTooMuchProcessorTime.
The same shell also sets the kernel's file-size limit (ulimit -f, whole kilobytes: fileSizeLimitForShell(_:)) from Limits.maximumOutputBytes, and the watchdog kills a child whose watched file passes that cap (KillReason.wroteTooMuch, "its output passed N MB"); a child the kernel ends at the limit (SIGXFSZ) is reported the same way, since a check once a second let a fast writer put hundreds of megabytes on the disk between two looks. runCapturingOutput(_:arguments:limits:maximumOutputBytes:...) keeps what a child prints (afinfo's): its standard output goes to a new hidden .<UUID>.watched-output file in the temporary directory, which is the watched file, capped at maximumOutputBytes (1 MiB unless asked otherwise) and removed however the run ends, by an exit, a kill, a failure to start, or a cancellation; there output is not progress, so the stall clock runs from the child's start, and a child that prints without end still ends at its time limit while one that prints only when it ends (afinfo) is not killed for being silent.
A reason's words (KillReason.words) count its seconds with CountWording.seconds, so a limit of one second reads "1 second".
The watchdog's clock is ProcessInfo.systemUptime, which never runs backwards, so a sleep or a change of the wall clock never ages a healthy child.
ChildGate holds the child's pid and whether its task was cancelled under one lock, so a cancellation and the child's start meet in either order and the child is killed all the same, and a task already cancelled starts no child.
Every running child is in a registry that terminateAll() kills with SIGKILL, taking a short lock and never waiting for a child; applicationWillTerminate and PlaybackMemoryGuard.quitAtOnce() call it. startReaper(watching:parent:) starts a /bin/sh loop that checks each second and kills the child once TextMouth's own pid is gone, however TextMouth went (quit, force-quit, or the memory guard's _exit), and ends by itself when the child does; a reaper that cannot start is not an error for the run.

## OrphanedConversionSweep
<!-- id: orphanedconversionsweep; keys: orphan sweep, leftover afconvert, leftover afinfo, launch cleanup, libproc, stale temporary files, storage log; src: TextMouth/Platform/macOS/Services/OrphanedConversionSweep.swift, TextMouth/Services/ImportAudioConverter.swift, TextMouth/Platform/macOS/Services/WatchedProcess.swift, TextMouth/Platform/macOS/App/AppDelegate.swift -->

OrphanedConversionSweep (Platform/macOS/Services/OrphanedConversionSweep.swift) deals with the converters an earlier TextMouth left running. applicationDidFinishLaunching calls sweepInBackground() once, on a utility queue and never in a hosted test: it lists the processes through libproc, reading each command line with sysctl(KERN_PROCARGS2), and kills with SIGKILL each one that is /usr/bin/afconvert, is run by the current user, is an orphan (parent pid 1), and has as its last argument a hidden temporary output name of TextMouth's (a last path component that starts with "." and ends with one of the suffixes ImportAudioConverter.isTemporaryName(_:) knows, with something between: .audio-conversion.m4a, the .ogg-conversion.m4a an earlier version used, and .audio-downmix.caf).
One OGG_ORPHAN_SWEPT line counts what it killed. sweepAfinfoInBackground() (FMT09, also called at launch, never in a hosted test) kills with SIGKILL each /usr/bin/afinfo that is run by the current user, is an orphan, and has as its standard output, descriptor 1 (ProcessSnapshot.standardOutputPath, read with proc_pidfdinfo and PROC_PIDFDVNODEPATHINFO), a hidden .<UUID>.watched-output file (WatchedProcess.outputFileSuffix; shouldKillAfinfo), and removes from the temporary directory each such regular file more than an hour old (sweepCapturedOutputFiles(in:)); one AFINFO_LEFTOVERS_SWEPT line, in the storage category, counts what it did.

## Temporary names of conversions
<!-- id: temporary-names-conversions; keys: temporary file, .audio-conversion.m4a, long file name, exFAT, 255 units, Ogg book conversion, name collision, rename; src: TextMouth/Services/ImportAudioConverter.swift, TextMouth/ViewModels/LibraryViewModel+OggConversion.swift, TextMouth/Services/BookContentAnalysisService.swift -->

A conversion is written under the hidden name ImportAudioConverter.temporaryURL(beside:) makes, ".<UUID>.audio-conversion.m4a", built from the UUID alone (58 characters), so a track whose name is as long as the file system allows can be converted; removeLeftovers(in:) still finds it, and a downmix's CAF and an earlier version's .ogg-conversion.m4a, by isTemporaryName(_:). givingFinalName takes the track's stem with .m4a, else "<stem> 2.m4a" and on, each by one RENAME_EXCL rename (renameWithoutReplacing), and candidateName(stem:number:) drops whole characters from the end of the stem until the name is at most 255 UTF-16 units (maximumNameLength), each candidate fitted on its own.
A file system that refuses RENAME_EXCL (exFAT answers ENOTSUP) is served by reserving the name with an exclusive create and renaming over the empty reservation. convertOggBookAudio(ofBook:), the library's one-time conversion of its Ogg books (convertOggBooksOnce), reads a folder book's saved index (BookContentAnalysisService.load) before it converts anything, so a book whose index the commit would refuse waits with no minutes spent and no hidden file made, and commitTracks discards the converted files (ImportAudioConverter.discard) when it throws.

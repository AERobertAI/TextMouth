# Shared helpers

Part of [TextMouth's architecture](../../ARCHITECTURE.md).

These small types each own one rule that several parts of the app follow; use them rather than writing the rule again.

- LibraryWindowRouter (Services/LibraryWindowRouter.swift): decides which window takes each app-wide action.
- WindowCommandRouting (Views/Library/LibraryView.swift): decides which of several open windows takes a menu command or keyboard shortcut posted as a notification: a shortcut goes to the window it was pressed in, a menu command to the key window, and a window not attached yet takes either. Every Library window asks it through LibraryView's takesCommand(_:), and a reader, which counts its own sheets as itself, asks it too, as does an audio editor window's model for the editor's own shortcuts.
- LibraryBookUpdates (ViewModels/LibraryBookUpdates.swift): how open readers learn that the library changed their book or is moving its files.
- ReaderRequestStore (Services/ReaderRequestStore.swift): the one store of requests that wait for a book's reader, Continue to Next Book's (ReaderAutoplayRequests) and the reading list's (ReadingListOpenRequests): one a book, claimed once, thrown away after 30 seconds unless the book's reader holds them while the book downloads, and dropped when the open they wait for is refused (ReaderOpenRefusal).
- LiveReadingPositions (ViewModels/LiveReadingPositions.swift): where readers are between checkpoints. A live position goes there, never into the library, which takes a reader's position only at its checkpoints.
- ReaderSnapshot and SheetOverOneReader (Views/Reader/ReaderSnapshot.swift): what a view shows of its reader, republished only when it changes, and sheets that compare equal while they show the same reader. A view over a playing reader observes a snapshot, never the whole reader.
- TextCacheFingerprint (Models/TextCacheFingerprint.swift): what a text cache was written from, checked by size and date before any file is read.
- MarkdownCacheService.chapterMarker(title:) (Services/MarkdownCacheService.swift): the line that starts a chapter in content.md, which EPUB extraction and a transcript's text both write.
- TranscriptText (Models/TranscriptTextIndex.swift): a transcribed audiobook's text with its timing, sentence by sentence: the sentence heard at a time, the place in the text for a time and the time for a place, and so the reader's audio cursor converted both ways. Search in Book, Where Am I?, and anything else that follows the narration in the text should use it rather than converting time again.
- TranscriptSentence.rewrite(as:) (Models/Transcript.swift): a transcript's sentence given new text, keeping its time in the audio and dropping its words' timings, which no longer fit. An edit in the user's editor (TranscriptEditing.apply) and a cleanup (TranscriptCleanup) both rewrite sentences through it.
- TranscriptAccuracy (Services/TranscriptAccuracy.swift): a transcript aligned word by word with the text that was read aloud, its words compared as the edit alignment compares them (TranscriptEditAlignment.key(of:)), with every apostrophe read as one; the differences sorted into the kinds of mistake a recognizer makes, its confidence weighed against them, and the corrections that would have been right in every place they apply. It is in the app rather than the tests so that later work, such as learning rules from the user's own edits, can use it.
- RowNoteBadge (Views/Library/BookCloudNote.swift): the outlined badge a library row's notes are drawn in, its cloud notes and its transcription note, with a picture hidden from VoiceOver, which only repeats the words.
- PersistenceFailureCenter (Services/PersistenceFailureCenter.swift): where every failed save is reported and settled.
- ImportStaging (Services/ImportStaging.swift): builds a package out of sight and publishes it with one rename.
- FileImportService.namesManagedPackage(_:) (Services/FileImportService.swift): whether a row names a package the library manages, by the package's name and folder, the one check that the deletion guard, the first launch's move of feed downloads, Move to Library…, and the return of a gone feed's downloads share; and Book.FileLocation.packageDirectory(inDataDirectory:) (Models/Book.swift): where a row's package is, the one package rule, which Book.packageDirectory(inDataDirectory:) and the audio editor's AudioBookPlace follow. FileImportService.isManagedPackageName(_:) and isSymbolicLink(_:) are the check's parts, which a feed item's own check shares (FeedItemPackage.isPackageName(_:) and packageForRemoval(of:in:)); TextMouthPaths.bookInfoFileName and contentMarkdownFileName name a package's record and text; and LibraryListCache.index(of:) gives each book's place in a list by ID, the first of an ID winning, for the list cache and the feed rows' lookup (FeedItemRowLookup) alike.
- AudioEditHistoryStore and AudioEditPackage (Services/AudioEditing/): the one way to change a book's audio edit history, under one lock for the whole process, and where a package keeps that history, its originals, and its takes, with the one check that a path a history records stays inside the package.
- DataDirectoryMigrator and DataDirectoryLocation (Services/DataDirectoryMigrator.swift): copy a whole data directory out of sight and publish it with one rename, and take a location as the real folder its links lead to.
- StorageBoundary and StorageGeneration (Services/StorageGeneration.swift): where the data directory is now, and the boundary that keeps the work writing into it from running across a move's publication.
- StorageDestinationAssessment, StorageChoice, and StorageWording (Services/StorageDestinationAssessment.swift): what a folder chosen for the library can become, judged from metadata alone, and the words that offer it.
- DataDirectoryMoveProgress and DataDirectoryMoveWording (ViewModels/DataDirectoryMoveProgress.swift): a move under way, with its Cancel, as every Library window's sheet, Storage settings, and VoiceOver present it.
- OffMainWork (Services/StorageDestinationAssessment.swift): runs blocking work, such as reading or copying a folder that can wait on a drive or the network, on a background dispatch queue, and hands back its result without holding the main actor.
- ArchiveExtraction, ArchiveBudget, ArchiveEntryReader, and IndexedArchive (Services/ArchiveExtraction.swift, Services/ArchiveBudget.swift, Parsers/ArchiveEntryReader.swift): bounded, cancellable ZIP extraction, the one way to read an archive entry, and the one way to find many entries.
- ImportScratchSpace (Services/ImportScratchSpace.swift): where imports stage packages and extract archives, on this Mac or beside the library.
- SettingsPolicy (Models/SettingsPolicy.swift): the table of every validated preference.
- StoredPreference and PreferenceObserver (Models/StoredPreference.swift): one definition of each preference's key and stored form, and notice of its changes.
- KeyBinding.keyNames and KeyBinding.accessibleDisplayString (Models/KeyboardShortcut.swift): the one table of named keys, with each key's words, what the screen shows, and config.json's name, and a shortcut in words, single or double, which the Shortcuts tab, its announcements, the audio editor's hints, and config.json all read. Say or write a key through them rather than naming it again.
- VoiceOverAnnouncer (Services/VoiceOverAnnouncer.swift): every VoiceOver announcement, recorded instead under tests. announceAfterSheetCloses(_:from:), and AnnouncementAfterSheet for a sheet's owner, say what a sheet's work did VoiceOverAnnouncer.afterSheetDelay, 0.6 seconds, after the sheet closes, so the closing never cuts it off (REV11 F6): a subscription, the Move sheet's note of the items it left, Move to Library…, and the Remove question's Delete Download use them, and the feed's own confirmations, Unsubscribe's, Delete Episode's, and Delete Feed's, wait the same way through afterSheetCloses(_:), as does the feed downloads section's Cancel, which moves VoiceOver's focus to the list first and speaks after it (REV13 items 1 and 3).
- focusing(_:first:_:) (Views/Transcription/TranscriptionSheet.swift): marks a sheet's control that takes keyboard focus while the sheet's focus is on it, and that VoiceOver moves to once when it becomes the sheet's first control; the Transcribe Audio sheet and the Clean Up sheet both mark theirs with it.
- VoiceCatalog (Services/VoiceCatalog.swift): the installed voices, listed once off the main thread and again when the system's voices change. Offer its list rather than asking the system for the voices.
- SpeechMarkupGuard (Services/SpeechMarkupGuard.swift): makes tag-shaped text, and the NUL character, harmless to the speech engine at the same UTF-16 length, so an offset into the guarded text is an offset into the original. Every utterance made from a book's text, or quoting a book, as Where Am I? and Speak Info do, goes through it. neutralizedStrictly(_:) silences every bracket, tag-shaped or not, and neutralized(_:strictlyWithin:) does so within a range of a text, for the rest of a chunk the engine refused; neither touches the ampersand.
- TextMouthRuntime (App/TextMouthRuntime.swift): the one switch that keeps hosted tests away from the user's data, and the sandbox it gives each test process instead, deleted when the process is done with it.
- ViewBodyCounter (Views/ViewBodyCounter.swift): how many times a view's body ran, counted in Debug builds for the tests that check what a change redraws.
- DatalessFiles (Models/CloudStorageContract.swift): whether a file's content is only in the cloud, and running work that must never download with dataless files left there.
- LibraryIndexQuarantine (Services/LibraryIndexQuarantine.swift): keeps a file beside itself, never changing the original, under a name marker of the caller's own, .unreadable- for the stores and transcript.json and .edited- for Edit Text's copies of content.md, using an earlier copy of the same bytes again; SavedFile.preserveUnusable reaches it with dataless files left in the cloud.
- SavedFile (Services/SavedFile.swift): reads a small file that TextMouth reads whole and replaces whole, one another Mac writes too or one of this Mac's own, with dataless files left in the cloud, telling a missing file, one only in the cloud, and one that can't be read apart, and preserves one that can't be used before anything replaces it. SavedFile.renameReplacing(_:_:) is the one rename(2) helper, which puts a file in place of another in one step: the log writer's rotation, the reading-text cache, and a filtered audio render's result use it. SavedFile.OnDiskMemory is the one memory of what this process last read or wrote of some files in one data directory (holds(_:for:at:), remember(_:for:), forget(_:), startOver(unlessIn:)), so a save writes a file only when its freshly encoded bytes differ: library.json and each feed's index use it (see [the library index](state/library-index.md)). The caller must encode the same content to the same bytes, with sorted keys and a fixed row order, and confine the value to the queue it reads and writes on, since it does no locking of its own.
- MachineLocalPaths (Models/CloudStorageContract.swift): this Mac's own folders, which never sync: its Logs folder, the working copies, import staging, archive extraction, the takes being recorded (MachineLocalPaths.recordings, in Services/RecordingTake.swift), the feeds' downloads waiting to be imported (MachineLocalPaths.feedDownloads, in Services/Feeds/FeedStore.swift), and, in its Caches folder, the kept reading text, the feeds' fetch details and resume data, audio editing's scratch folders (AudioEditScratch, in Services/AudioEditing/AudioEditComposition.swift), and the audio editor's clips (AudioEditCaches.clipsRoot, in Services/AudioEditing/AudioEditCaches.swift).
- NetworkReachability (Services/NetworkReachability.swift): whether this Mac is online, from one NWPathMonitor, or a test's answer.
- MaintenanceFileAccess (Services/MaintenanceFileAccess.swift): how maintenance asks whether a book's files are in the cloud, and reads them without downloading.
- DiagnosticLog (Services/DiagnosticLog.swift): what a log line may say, and which lines are written.
- LogWriter and TextMouthPaths.logDestination (Services/LogWriter.swift, Services/TextMouthPaths.swift): the one writer of log files, and the one place that decides each line's folder.
- AsyncBridge (Services/AsyncBridge.swift): lets synchronous parsing and analysis wait for async work, such as reading audio through AVFoundation. The work runs at the waiter's priority or .medium, whichever is higher (waitPriority(for:)), so no thread waits on work of lower priority (#1581).
- AudioSegment and AudioClipChain (Models/AudioSegment.swift, Services/AudioPlaybackService.swift): a segmented chapter's clips, never an empty list, and the one conversion between a time in the chapter and a time in a clip's file.
- TimeLeftEstimate and WorkTiming (Models/TimeLeftEstimate.swift): what the finished items of a run took, each by its size where that tells its time, and the time the items still to come should take, rounded as it is said: the one estimate the import overlay and the feed downloads section share, worded by ImportProgressWording.timeLeft(_:).
- PlaceClock (Models/PlaceClock.swift): the clock that names a book's places by times, an audiobook's recording or a text book's words at its speed, and finds the place a time names (P08): Go to Time, the Headings sheet's Time In, and Copy Reading Position's place count on it (the reader, above). PlaceClock.end is its last chapter at its full length, at the clock's length; span(from:to:) adds a span chapter by chapter, so whole chapters last exactly their durations, where subtracting two times carries the rounding of the running total before them (the Headings sheet's Durations).
- TimeEntry (Models/TimeEntry.swift): reads a time typed or pasted into one field as people write it, "1:02:03", "62:03", "3723", or "12:04.3", for the audio editor's Go to Time and Insert Silence and the reader's Go to Time (JumpInputValidator.time(_:length:count:)); it moved from the audio editor, where it was AudioEditorTimeEntry, with P08.
- ProgressObserver (Views/ContentView.swift): a view that observes one progress object alone and draws what its caller makes of it, so the window around it, and the library model, are never redrawn for the progress; the text cache's overlay and Storage rows, the import overlay, and the feed downloads section (FeedDownloadProgressObserver, since the feed follow-ups after FR14) use it.
- FeedDownloadWait.networkWait (Services/Feeds/FeedDownloadManager.swift): the one wording of a wait for a network, "downloads once this Mac is on a network without data limits", which an item's row says as its reason and a download refused on a network with data limits says as its message (FR14, REV13 item 4).
- Book.hasOwnSettings (Models/Book+OwnSettings.swift): whether a book keeps a setting of its own, a voice, speed, or pitch, skipped headings, its end-of-book choice, or a skip unit, the one rule by which a feed item's package is kept once its file goes (FeedItemPackage.holdsListenerState) and by which Delete Download and the library's Remove name its "own settings" (FeedWording.KeptParts).
- CountWording (Models/CountWording.swift): a count with the right singular or plural word, so the screen and VoiceOver say the same thing (hours(_:), minutes(_:), and seconds(_:), as in "1 minute", which TimeFormatting.spoken's durations use too, and part(_:of:singular:plural:), as in "0 of 1 book", the noun agreeing with the whole), a time kept in tenths of a second (secondsToTheTenth(_:), "0.5 seconds" or "2 seconds", for the gesture time window and the double-press time), how far a batch has got, as in "3 of 10 books processed" and "0 of 1 book processed" (part(_:of:_:), with the CountWording.Noun a progress overlay counts by, ProgressOverlay.itemNoun: ImportProgressWording.itemNoun and TextExtractionProgress.itemNoun, REV13), and the library's books with its feeds beside them, as in "743 books, 2 feeds" (booksAndFeeds(books:feeds:), FR11), which every count of the library's books uses; where episodes and articles are listed beside books, as in Recently Opened and the Reading List, each kind is counted apart, "9 books, 1 article" (listItems(books:episodes:articles:feeds:) and listItems(of:feeds:), of which booksAndFeeds is the case without feed items), and a section is headed the same way, "Books (9), Articles (1)" (booksHeader(of:)). CountWording.list(_:) is the one "a, b, and c" joiner, which the cloud, removal, feed, shortcut, and filter wording use.
- ManualBookOrder and LibraryBookSorter (ViewModels/LibraryViewModel+SortAndOrder.swift, Models/LibraryBookSorter.swift): the library's orderings. Manual order (by position, then title, then book ID) is the one order a folder's list, Move Book Up and Down, dragging, and Continue to Next Book all follow; the reading list keeps an order of its own (ReadingList), which Move Book Up and Down and dragging rearrange at the Reading List through the same LibraryReorderTarget.
- RemovalWording, FeedDownloadRemovalWording, OperationOutcome, ReadingStatsTileWording, ImportDecisionWording, BookExportWording, BookTextEditWording, TranscriptionWording, TranscriptCleanupWording, AudioEditWording, ReadingListWording, ReadingListReaderWording, EndOfBookWording, ReaderTimeWording, ImportProgressWording, FeedDownloadProgressWording, and SpeechRefusalWording (Models/, FeedDownloadRemovalWording in RemovalWording.swift and the last in SpeechRefusalReport.swift): the wording of removals, the Remove of a feed's downloads, operation results, statistics, import questions, Export, Edit Text, transcription, the transcript cleanup, audio edits, the reading list, a book read from it, the end of a book, with the one word, "Finished" (EndOfBookWording.finishedProgress, P07), that the library row, Speak Info, Where Am I?, and Copy Reading Position say of a book resting at its end, while the reader's status row keeps its percent and time, the reader's times (its jump fields' labels, refusals, and announcements, the copied place, and the speed named beside time left and total), an import's progress, the feed downloads' progress, which says its sizes, its time left, and its lines to VoiceOver as an import's progress does (ImportProgressWording.spokenStatus(title:lines:)), and the report of a speech refusal, each built once for both the screen and VoiceOver.
- LibraryInfoWording (Models/LibraryInfoWording.swift): every sentence Speak Info says of a book, a folder, or a feed, brief or full, made from facts alone (BookInfoFacts, FolderInfoFacts, and FeedInfoFacts) and pinned by LibraryInfoWordingTests without a window: counts through CountWording, times through TimeFormatting, dates through FeedWording.moment, and a feed's counts through its row's own phrase, FeedWording.countsPhrase.
- LibraryCloudWording (Models/LibraryCloudWording.swift), ReaderCloudWording (ViewModels/ReaderViewModel+CloudDownload.swift), DataDirectoryUnavailableText (Views/Library/DataDirectoryUnavailableView.swift), RecordingWording (Views/Recording/RecordingWording.swift), AudioEditorWording (Views/AudioEditor/AudioEditorWording.swift), and BookSettingsWording (Views/Reader/ReaderView.swift): the wording of the list's cloud commands, of the refusal of books only in the cloud by operations that never download (LibraryCloudWording.downloadFirst(count:) and notDownloaded(titles:), which a move of the library, Export, and Edit Text share), of a reader's download, the Library Not Available screen, the Record window, the audio editor window, and a book's own settings, their sheet, toolbar button, and the saving and resetting of its voice, speed, and pitch, which the playback bar and the sheet share, each built once for both the screen and VoiceOver.
- FeedWording (Views/Feeds/FeedWording.swift and the files beside it): every word of the feed reader's interface, its rows, sheets, commands, notifications, and announcements, each label made by a function so the hosted tests can pin it.
- FeedItemPackage.removeWhole(_:in:remove:) (Services/Feeds/FeedItemPackage.swift): the one whole-package removal; a package already gone counts as removed.
- Book.isUnopened (Models/Book.swift) and Library.booksInFolderTree(_:) (Models/Library.swift) are the one definition of "never opened" and of "a folder's tree of books" (the library's own books in the folder and below it, never a feed's items): Book.isUnopened is read by the Unopened category, a row's New badge, Speak Info, a feed item's New and its kept package's test, and the recently opened sort; booksInFolderTree by a folder's emptiness test (hasBooks(inFolderTree:), which stops at the first book), its book counts, and its Speak Info. Delete Folder… lists the books it removes with booksInFolderTree, and Library.removeFolderAndContents(id:) removes the same books, so a feed's item that names a folder is neither deleted nor dropped; Library.isPath(_:inTreeAt:) is the one "is this path the folder or below it" rule, by whole path components, which the folders, their sort settings, and the books all follow.
- Array's subscript(safe:) (TextMouthProductionTests/CollectionTestSupport.swift) is the tests' one way to read an element they have not proven is there, so a break in the code under test fails an assertion rather than trapping the test host.
- AudioManifestLocation and AudioManifest.read(inAudioFolder:) (Parsers/AudioManifest.swift): where an audiobook's manifest lies, at the top of its audio folder or inside its one folder, and how its names are spelled from there.
- AudioTrackPlan (Parsers/AudioManifest.swift): the one arrangement of a multi-file audiobook's tracks, their order, titles, group headings and levels, and the pause after each, used by the parser and by ChapterPauses.
- ChapterPauses (Models/ChapterPauses.swift): the reader's one source of pauses between chapters.
- ReaderViewModel.headingAnnouncement(arrivingAt:in:): what a heading jump says, every heading at the place it reaches, the outermost first.
- PackageFileEditing (Services/PackageFileEditing.swift) holds what Edit Text and Edit Manifest share: the first-use explanation, worded for each kind, the app chooser, the workspace opener, the watcher of a file in a book's package, TextMouth becoming active, and the announcements kept until it does.
- ObjCException.catching(_:) (Services/ObjCException.swift) runs a framework call that may raise an Objective-C exception and returns it, so a raise cannot end the app. It wraps the ObjCExceptionCatcher static library in Vendor/, built as LAME is, with a module map; it is the only Swift file that imports it (B08).

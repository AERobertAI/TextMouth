## Rules (settled)
1. **Every page of the PDF is a page**, in order, with a block marker (`MarkdownMarkerWriter.write(MarkdownPageMarker(label:ordinal:).markdown, inline: false, into:)`) before that page's text, and before that page's outline headings when the PDF has an outline. Its label is `PDFPage.label` (PDFKit gives the `/PageLabels` labels: "i", "ii", "1", "2", "A-1"; and "1", "2", "3" for a PDF without them), trimmed; a nil or empty label is the ordinal, the page's index plus one.
2. **A page without text keeps its marker**, so several markers can share a place (blank pages, pictures OCR found nothing in); its outline headings are still left out, exactly as now (the outline path writes headings only for pages with text).
3. **The reading text is unchanged:** a page boundary stays the paragraph boundary it is now. Every marker is a block, and blocks add no reading text. Joining a sentence that runs across pages would move places, so it is not done.
4. **With `includesPages: false`, the Markdown is byte for byte what it was** (both paths: the plain join of `pageTexts` and `buildMarkdownWithOutline`).

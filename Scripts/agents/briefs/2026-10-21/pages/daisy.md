## Rules (settled)
1. **With `includesPages: false`, the Markdown is byte for byte what it was**: `pagenum` still reads "[Page N]" on its own line, and a DAISY 2.02 page fragment's words are still read.
2. **DTBook** (DAISY 3, NIMAS, and a standalone DTBook file): a `pagenum` element (any `page` attribute: front, normal, special) is a page, labelled by its text (normalized as `MarkdownPageMarker` normalizes); an empty one is labelled by its ordinal, the number of `pagenum` elements this converter has read, plus one. Its text is never read. It is written through `MarkdownMarkerWriter` where it ends:
   - at a block boundary (the Markdown so far is empty or ends with a line break), as a block (`inline: false`): a `pagenum` between paragraphs, or opening a `level`;
   - inside running text, inline with `keepingWordsApart: true`, so "before<pagenum>12</pagenum>after" reads "before after";
   - the old `ensureNewline()` before it and the "]\n" after it are not written.
   The text inside `pagenum` goes to a label buffer, not to the Markdown, while pages are included; `closeOpenElements` after damage still writes the marker of a `pagenum` it closes.
3. **DAISY 2.02:** the NCC's page entries are `span` elements whose `class` lists `page-normal`, `page-front`, or `page-special`, each holding a link to a SMIL `par` (or `text`) by fragment. Each is a page, labelled by the span's text (normalized; an empty one by its ordinal in the NCC). Its SMIL target's `text` element's `src` names the content fragment holding the page number. Where that fragment is one of the references the book reads (`extractDAISY202Fragments`), a block marker is written in its place and its words are not read (mark it read in the ledger, so an enclosing fragment read later leaves it out too). A page whose fragment the book never reads is dropped.
4. **The DAISY 2.02 converter calls** (`convertDAISY202FragmentElement`, `convertDAISY202WholeFile`) pass `includesPages` to `HTMLToMarkdownConverter.convert`, so with false they convert exactly as before.
5. **The reading text changes** where "[Page N]" or a 2.02 page number was read; nothing else changes. PG09 moves places.

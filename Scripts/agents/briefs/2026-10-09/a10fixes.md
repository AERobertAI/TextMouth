## Why
A read-only auditor (`a10audit`) read the app for A10 on October 10 (TODO-2026-09-04.md: "Audit fixed sizing, redundant choices, and spoken hints"). Its findings, with file and line on main around 1c57ac77, are below; re-find each. The user reads with VoiceOver and a braille display, by keyboard. Their standing rules: no two controls that do the same thing for most books (a field beside a stepper, or a slider beside a stepper, as a fine and coarse pair, is fine), and nothing conveyed by sight alone. Apple's hint rule: a hint describes the result and never names a gesture.

## Items, one commit each (group trivial wording fixes of one kind into one commit), each with its tests
1. **Settings may clip most of its controls:** the window is a fixed 700 by 540 points (`SettingsView.swift` about 57; the scene cannot grow, `TextMouthApp.swift` about 70), and every tab is a plain `Form`, which on macOS does not scroll; Playback, Storage, and Shortcuts are estimated at twice the height. Make each long tab scroll (`.formStyle(.grouped)` or a `ScrollView`, whichever keeps VoiceOver's reading order and the controls' labels), and add a hosted test that compares each tab's fitting height with the window, so this never returns unseen.
2. **The capture-group hint is wrong:** the substitution rule editor says "backslash 1" (`SubstitutionsSettingsView.swift` about 497; the comment at `TextSubstitutionService.swift` about 632 repeats it), but NSRegularExpression needs `$1`: "In a regular expression, $1, $2, and so on put back what each group matched."
3. **Hints that name a gesture or a fixed key:** "Double-tap to open folder" (`LibrarySubviews.swift` about 299) → "Opens the folder."; "Double-tap to select/deselect" (about 473) → "Selects this book." / "Deselects this book."; "Double-tap to navigate to this bookmark" (`BookmarkPanelView.swift` about 705) → "Goes to this bookmark and closes the list."; "Double-tap to navigate. Use context menu to skip or include this section." (`HeadingNavigatorView.swift` about 548) → "Goes to this heading and closes the list.", and offer Skip and Include as VoiceOver actions of the row, as bookmark rows offer theirs; the shortcut recorder's "Click to record a new shortcut" and "Press any key to set, or click to cancel" (`KeyboardShortcutsSettingsView.swift` about 414 and 419) → "Records a new shortcut." and "Press the new key, or Escape to cancel."; the book row's "Press Enter to open, Command I for info" (`LibrarySubviews.swift` about 474) → "Opens the book."; the sleep timer field's "use the stepper arrows" (`SleepTimerView.swift` about 224) → name the Adjust minutes stepper and its step; the bookmark list's empty state "Press Cmd+B" (`BookmarkPanelView.swift` about 198) → the key in force in words, or none; `MiscellaneousSettingsView.swift` about 76's "(default ⌘⇧R)", shown as signs on a braille display, and its "Keyboard Shortcuts" (the tab is "Shortcuts"). Update the tests that pin the old words.
4. **Two "Exit edit mode" buttons** (the toolbar's, `LibraryView.swift` about 448-461, and the edit bar's Done, `LibrarySubviews.swift` about 51-53, both running `clearAllSelections()`): drop the bar's Done; the toolbar button and Command-E remain.
5. **Read twice or read wrong:** the reader info bar's sleep timer (label "Sleep timer: 4:59 remaining" and value "4:59", `ReaderView.swift` about 1190-1191): drop the value; six slider labels say "slider" (`SettingsView.swift` about 120 and 143, `ReaderView.swift` about 908 and 935, `MiscellaneousSettingsView.swift` about 42 and 113): drop the word; captions that repeat a control's value or hint (`SettingsView.swift` about 110, 133, 250, 279, 305, 334; `ReaderView.swift` about 889, 917; `MiscellaneousSettingsView.swift` about 33, 104; `AudioEditorCommandViews.swift` about 110): hide them from VoiceOver, as `DoublePressTimeStepper` does; "Adjust minutes, 30" (`SleepTimerView.swift` about 228): value "30 minutes"; the bookmark row's date, shown but not spoken (`BookmarkPanelView.swift` about 698; `Book.swift` about 1230-1237): add it to the label.
6. **Plural slips** (through `CountWording`): "1 books selected" (`LibraryView.swift` about 460), "Select all 1 books" (`LibrarySubviews.swift` about 40), "0 of 1 books selected" (about 59), "1 rules (1 enabled)" (`SubstitutionsSettingsView.swift` about 60), "Timer set for 1 minutes." (`DocumentContent.swift` about 347, via `SleepTimerView.swift` about 330), and the custom timer's "1 minutes" (`SleepTimerView.swift` about 223 and 236).
7. **The heading filter's choices** read "H1–H1" with an en dash (`HeadingNavigatorView.swift` about 230): "Level 1", "Levels 1 to 2", "All levels"; and the "Show levels:" text beside a picker called "Heading level filter" is a second stop for one control: one label.
8. **The save-to-defaults labels understate their effect:** "Save this book's speed to global settings" (`PlaybackControlsView.swift` about 110, its tooltip repeating it as the hint) and "voice and speed" (`ReaderView.swift` about 969) both run `saveSettingsToGlobal()`, which copies voice, speed, and pitch: one shared label naming all three.
9. **Lists that recycle rows under VoiceOver's cursor:** Search and Duplicate Finder results use `LazyVStack` (`BookSearchView.swift` about 406, `DuplicateFinderView.swift` about 345), which the Headings and Bookmarks panels avoid for that reason: follow them, minding the memory of long result lists, and say what you chose.
10. **Smaller:** the Text tab's Reset to Defaults replaces every rule without asking (`SubstitutionsSettingsView.swift` about 38): ask first, naming the count; the Import Book hint names four formats (`LibraryView.swift` about 1552): say "books in any format TextMouth reads"; "press Scan" (`DuplicateFinderView.swift` about 332) names a button titled "Scan for Duplicates"; `HeadingDisplayMode.accessibilityLabel` is unused; one command has two names, "Toggle Bookmark" in the menu (`MenuCommands.swift` about 418) and "Add Bookmark" in the Shortcuts tab: one name, keeping config.json's old name readable; the jump panels' one-letter stops "h", "m", "s", "%" (`ReaderView.swift` about 1341, 1457, 1464, 1471) and the sleep timer's "Custom:" and "min" (`SleepTimerView.swift` about 213 and 229): hide them where the field's label already says the unit, or say the word.

Leave for the user, and do not change: the Sort menu's reversing when the checked field is chosen again, and the audiobook speed sheet's text, stepper, and slider (`ReaderView.swift` about 1017-1032), both asked in `humanQuestions/2026-10-09.md`. The Record window's hints are `whereamikeys`'s.

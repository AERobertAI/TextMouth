# Task `loadwaits`: tests that guess how long the app takes wait for the app instead

Slug `tests-loadwaits`, branch `tests/loadwaits` from `team/tests`. Read `_common.md` beside this file first. Each item below waits a fixed time and then asserts, or waits on a condition with a deadline a loaded Mac can miss; the TODO and the orchestrator's triage (`build/orchestrator/oct30/triage-report.md` in the main checkout, lines 2198-2420) record most of them failing under load. For each: read the test, find exactly what it waits for, and wait on THAT (a condition polled with a generous deadline that fails with a message, a barrier such as `handleQueuedCallbacks()` (`AccessibilityTestSupport.swift` 126) for work queued on the main queue, an expectation the code under test fulfils, or a gate). Keep every assertion. A wait that proves something does NOT happen ("nothing more is asked for") may stay a fixed window, but only after the positive event it follows has been waited for.

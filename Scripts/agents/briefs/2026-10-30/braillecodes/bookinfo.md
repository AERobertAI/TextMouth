# Task `bookinfo`: Book Information's Braille File Characters pop-up, and Speak Full Info's sentence

Team `braillecodes`, lead `braillecodes-lead`. Your slug is `braillecodes-bookinfo`, your branch `braillecodes/bookinfo`, made from `team/braillecodes`. Read `Scripts/agents/briefs/2026-10-30/teams-common.md`, "The worker's part", first, and follow it.

## Background

A BRF or BRL braille book records the braille file characters its file is read with (`Book.brailleFileCode`, the id of a `BrailleFileCode`, `TextMouth/Parsers/BrailleFileCode.swift`; nil reads as North American Braille ASCII; an id this TextMouth lacks is kept and refused by name). On the team branch already: `Book.offersBrailleFileCodeChoice` (a BRF or BRL braille book, never a PEF or a feed item); `Book.recordedBrailleFileCode()` (the code that stands between row and package record); the re-read `LibraryViewModel.readTextAgain(bookID:choosing: .brailleFileCode(code), access:)`, which refuses, reads again, commits, and announces exactly as the encoding's re-read does (`TextMouth/ViewModels/LibraryViewModel+TextEncoding.swift`); and `BrailleFileCodeWording` (`TextMouth/Models/LibraryInfoWording.swift`) with the re-read's refusals.

Book Information already has the encoding's twin of what you build: the Text Encoding pop-up (`TextMouth/ViewModels/TextEncodingChoiceModel.swift`, read it whole; `TextEncodingPopUp` and `textEncodingConfirmation(_:)` in `TextMouth/Views/Library/LibrarySheetViews.swift`, lines 158-211; the sheet, lines 1-156). The research (`BRAILLE-CODES-RESEARCH-2026-10-25.md`, section 8.3, the Book Information paragraph) asks the braille pop-up to follow it, its alert, its re-read flow, its busy refusals, and its accessibility wording, value first, **sharing code with it wherever the two do the same thing** (the project's DRY rule), with three differences: no "Automatic" and no "guessed", since nothing is guessed; an alert that says nothing checks the choice; and the reader's refusal when the file holds a byte the chosen code has no cell for.

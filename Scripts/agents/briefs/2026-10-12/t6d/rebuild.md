# t6d task "rebuild": a rebuild of a book's text moves its places, and the cache batch commits them

Slug `t6d-rebuild`, branch `t6d/rebuild`, board task in your launch prompt. Read `worker-common.md` beside this file first. Two commits, in this order. This is the core of branch D: the user's reading positions, bookmarks, and skipped headings pass through it, so follow the order of operations exactly.

## Background
Every rebuild of a book's text writes content.md in one place, `MarkdownCacheService.writeCache(for:)`: the launch's cache batch, Redo Text Extraction, the statistics pass's and the reader's rebuild of an outdated or changed cache, the legacy migration, and an EPUB whose title was written into its file (which reaches it as a changed source). The team's earlier tasks built the parts:
- `Book.holdsPlacesToMove`, `Book.relocatablePlaces`, and `Book.takeMovedPlaces(original:moved:)` (each moved place taken only where the book still holds it exactly as it was, so a place saved meanwhile wins), and `Book.waitingSkippedHeadings`;
- `PlaceSnapshot.keep(textAt:record:in:)`, `PlaceSnapshot.movePlaces(to:at:)` (nil when nothing needs writing, having deleted the copy), and `MovedPlaces` (`original`, `moved`, `snapshot`, `discardSnapshot()`), in `TextMouth/Services/PlaceSnapshots.swift`.

This task wires them in. The design's steps (TEXT-ANCHORS-ADDENDUM-2026-10-10.md, section 9): 1. copy the old content.md aside with the book's places as they are, when the book holds a place to move and its old content.md is on this Mac; 2. write the new content.md; 3. move the places from the copy to the new text; 4. commit them with the analysis (`LibraryPersistenceService.saveContentAnalysis`), each only if it is still as it was at step 1; the row takes them through the batch's summary; 5. delete the copy once the record holds them. (Step 6, a launch finishing a copy left behind, and the reader's own rebuild are other tasks.) Left alone: a book whose files are in the cloud and not downloaded, and a book held by an Edit Text session, whose places branch E moves.

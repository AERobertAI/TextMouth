## What the lead confirmed in the code (main 8cfdc5bb + briefs)

**Finding 1 (data loss).** Import Folder… sends each chosen folder to `LibraryViewModel.importSingleFileAsync(from:)` (`TextMouth/ViewModels/LibraryViewModel+Import.swift:542-574`), which calls `FileImportService.importFileWithReport(from: url, …)` and then `completeSingleImportedBook(imported, originalURL: url, …)` (:592-618). The decision to delete is one line: `let deletableOriginal = imported.mayDeleteOriginal ? originalURL : nil` (:602); with Delete After Import `originalFileQuestion(for:)` then calls `deleteOriginalFile(at:)` on that URL at once (`LibraryViewModel+Duplicates.swift:117-128`, :383-402), and with Ask Each Time the user's Yes does the same. `FileImportService.deleteOriginalFile(at:)` (`FileImportService.swift:1690-1698`) trashes the item, or removes it for good when "Move to Trash instead of deleting" is off.

`ImportedBook.mayDeleteOriginal` is `!keepsOriginal && !isFromPackageFolder` (`FileImportService.swift:60-92`, the flag at :71, the property at :83). The loose-DAISY branch sets the flag (`imported.isFromPackageFolder = package != nil`, :861-862). The folder-of-tracks branch does not: `importFileWithReport(from:checksum:…)` returns `importAudioFolderWithReport(…)` directly (:795-799), and that function (:994-1050) returns `publishTracks(…)`'s result with the flag false. So importing `~/Audiobooks/Night Ferries` (tracks, cover.jpg, lyrics.txt, a Bonus folder) with Delete After Import trashes the whole folder, though only the audio files and the manifest were copied. `docs/user/adding-books.md:9` promises "the folder is left as it was".

**Finding 2 (feeds finding 1).** `isFolderOfTracks(_:)` (:979-992) counts audio anywhere beneath the folder (`AudioBookParser.audioFiles(in:)` recurses, `AudioBookParser.swift:35-66`), but `BookFormat.detect` and `DAISYParser.packageEntryPoints(in:)` (`DAISYParser+PackageInventory.swift:43-59`) look at the top level only. A parent folder of DAISY book folders, which `packageEntryPoints` documents as "not itself a book" and which used to be refused, now imports as ONE audiobook of every book's audio files, gigabytes, in name order. The ZIP batch already treats such folders as books: `importCandidates(in:unpacking:)` (:1402-1438) enumerates the folder, skips `__MACOSX` with `skipDescendants()`, and calls `DAISYParser.packageEntryPoints(in:)` on each directory.

## The problem
TextMouth converts Ogg audio by running `/usr/bin/afconvert` as a child (`WatchedProcess`). When TextMouth is force-quit, or exits through the memory guard's `_exit`, the child is reparented to launchd (pid 1) and keeps running, holding memory and CPU, until it ends or the Mac restarts. Another worker makes new children die with the app; this sweep deals with the ones already left behind (and any a reaper missed). Its output argument is always a hidden temporary name beside the book's tracks: `.<something>.ogg-conversion.m4a` (the last command-line argument; today `.<stem>.<UUID>.ogg-conversion.m4a`, after the naming task `.<UUID>.ogg-conversion.m4a`: accept both, by the prefix "." and the suffix `OggAudioConverter.temporarySuffix`).

## Required behavior
1. `OrphanedConversionSweep.sweep(processes:kill:) -> [pid_t]`: given a list of processes and a kill closure, kills (SIGKILL) and returns the pids of exactly those that are ALL of: the program is `/usr/bin/afconvert` (compare the executable path from `proc_pidpath`); owned by the current user (`geteuid()`); orphaned, that is, parent pid 1 (a live TextMouth's own converter, or another copy of TextMouth's, has its parent alive and is never touched); and its last argument is a path whose last component starts with "." and ends with the temporary suffix. Nothing else is touched, however similar: another app's afconvert (any other output name, a visible `.m4a`, a hidden file with another suffix), a converter whose parent is alive, another user's, any other program with such an argument.
2. `OrphanedConversionSweep.runningProcesses() -> [ProcessSnapshot]` (`pid`, `parentPid`, `userID`, `path`, `arguments`), the real lister, using libproc: `proc_listallpids`, `proc_pidpath`, `proc_pidinfo(PROC_PIDTBSDINFO)` for the parent pid and uid, and `sysctl` with `KERN_PROCARGS2` for the arguments (layout: Int32 argc, then the executable path and NUL padding, then argc NUL-terminated strings, then the environment). Parse defensively: a process that ends mid-listing, a buffer that is short or has a bad argc, or a permission failure skips that process and never traps.
3. `static func sweepInBackground()`: runs the sweep once, off the main thread (utility priority), with the real lister and `kill`, and logs one line when anything was killed: `DiagnosticLog.event(.storage, "OGG_ORPHAN_SWEPT: killed N leftover afconvert process(es)")`, nothing otherwise. It does nothing in hosted tests (`TextMouthRuntime.current.isHostedTest`), as the memory guard's `tellOfAQuitToProtectTheMac` does.

## Tests (new class `OrphanedConversionSweepTests`; fabricated `ProcessSnapshot`s for the rules, real processes only to test the lister)
- The rules, each case on its own: killed: an orphaned afconvert with output `/Users/x/Book/.01.<uuid>.ogg-conversion.m4a`, the same with the short name `.<uuid>.ogg-conversion.m4a`, with spaces and non-ASCII in the folder; spared: parent alive (pid 4321), another uid, a different program with the same arguments, afconvert with output `/Users/x/Book/01.m4a`, with `.hidden.m4a`, with a name that has the suffix but does not start with ".", with no arguments, with an empty string argument; several in one list: exactly the right ones, and the `kill` closure called once for each, with SIGKILL.
- The lister, on live processes: it finds this test host by `getpid()` with its path, its parent pid equal to `getppid()`, `userID == geteuid()`, and its first arguments; a child you start (`/bin/sleep` with the argument `30`, terminated and waited for in `tearDown`) is listed with its path `/bin/sleep`, its parent pid `getpid()`, and `30` as its last argument, parsed right (BSD `sleep` takes one operand, so give it no more); a pid that does not exist is skipped; the listing finishes in under a few seconds and holds at least 10 processes.
- `sweepInBackground()` does nothing and kills nothing in the test host.

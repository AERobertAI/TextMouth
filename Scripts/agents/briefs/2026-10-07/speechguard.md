## Items, one commit each, each with its tests
1. **The guard.** `SpeechMarkupGuard.neutralized(_ text: String) -> String`, same length in UTF-16 as its input: inside every tag-shaped run it replaces `<` with U+2039 and `>` with U+203A and changes nothing else. Tag-shaped: `<`, optional spaces, optional `/`, optional spaces, a name of one or more characters other than `<`, `>`, and whitespace (for an opening tag the name must start right after `<`: a letter, `?`, `!`, or `/`; for a closing tag spaces are allowed as the engine's own regex allows them), optional attributes or spaces (anything but `<` and `>`), then `>`. A `<` with no `>` after it in the text, and a `<` or `>` with spaces on both sides as in "x < y and y > z", stay as they are, so "less than" is still spoken for math and code. Doc comments carry the findings above (what the engine does, the frame counts, why same length). Tests, string in, string out: the Rainbows End sentence; a chunk starting after `<sm>`; `</ >`; `< /sm>`; `<p>inside</p>`; math untouched; `3 < 4.` untouched; `a<b` (no `>`) untouched; every output has the input's `utf16.count`; a text without brackets returns identical.
2. **Every utterance made from book text is guarded**: `SpeechService.makeDirectUtterance(speaking:)`, the single-word utterance (SpeechService around line 422), the engine render's utterance (AudioEngineService around line 861), and Where Am I's. Because the guard keeps length, every offset map, chunk range, and `currentWordRange` stays exact: add a test that speaking (through the recorder that stands in for the synthesizer in tests, see `makeDirectUtterance`'s comment) a text with `<sm>…</sm>` reports word ranges at the same offsets as the unguarded text would, and that the recorder received the neutralized text.
3. **Recovery.** When the live direct utterance is cancelled while the app expects playback (today's `DIRECT_CANCEL_UNEXPECTED` branch of `speechSynthesizer(_:didCancel:)`), the service replaces its direct synthesizer with a fresh `AVSpeechSynthesizer` (delegate reattached; the old one released) and speaks again from the cancelled chunk's start offset, once per chunk; log `DIRECT_SYNTH_REPLACED` and `DIRECT_RETRY offset=…`.

## Description

Since November 24, 2026, a Mac builds with every size setting (full link-time optimization) only for make install and make release, and every other build on a Mac is light (Scripts/size_settings.py's profiles), because full LTO's link takes several GB of memory and froze the user's 8 GB Mac. Scripts/test/release-goldens.sh takes the profile auto: light on a Mac, full on GitHub Actions. But no workflow runs it on GitHub, so the app that ships, the full build, has no golden-test run anywhere: its last one was on the Mac on November 23 (132 tests, 0 failures, before the rule).

Fix: a GitHub job, at each version bump or on request through the build train, that runs release-goldens.sh with the full profile (every setting but -internalize-at-link) on a macOS runner, and reports through the train's results like the other jobs. Measure its memory and time there first: the full-LTO build of the app and its test bundle took about 65 minutes on the Mac.

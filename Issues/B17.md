## Description

AsyncBridge.swift, about line 202, tells the iPhone's listener that audio will work again once TextMouth is opened again. On the iPhone, switching back to the app does not start it afresh, so the remedy is not true there. DR34 fixed the same words in InProcessEngineWording to 'won't try again until TextMouth is closed and opened again' (review-phonebraille's finding 1); use the same remedy here, from a Wording enum.

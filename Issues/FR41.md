## Description

Open a password-protected book in every format that has a password scheme other than DRM, and put a password on a book that has none. Design: research/PASSWORD-PROTECTED-BOOKS-2026-11-24.md.

The user's decisions, November 24, 2026:
- Unlocking is temporary by default: the book's text is held in memory while it is open, and nothing of it is written to disk.
- An option removes the password from the book completely once it is unlocked, rewriting the book's own file without it (never a second copy); TextMouth then treats it as any other book.
- A book can be given a password again, and a password can be remembered (in the Keychain: a hash can check a password but cannot decrypt).
- Until a protected book is opened and unlocked, every background job skips it: launch re-reads, cache rebuilds, metadata refreshes, Redo Text Extraction for many books, and search indexing.
- Mac and iPhone parity as much as possible; size does not veto it.

Open: the eight questions in humanQuestions/2026-11-24.md, and the cost of TextMouth's own 7z and RAR readers (the researcher's follow-up). Related: B27 (a password ZIP imports empty or short), B28 (an EPUB with DRM).

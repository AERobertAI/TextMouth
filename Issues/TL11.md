## Description

Scripts/l10n/scan.py, from the experiment in build/orchestrator/l10n/scan_strings.py: lexes every Swift string literal, sorts each by the call and declaration it sits in, reports the interface text by area and file, and a ratchet (make lint-l10n) that fails when a file gains interface text that is not localized.

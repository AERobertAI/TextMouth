## Description

Found at the first real make install-ios (Nov 27). Xcode 27's devicectl lists simulators (hardwareProperties.reality "simulated"), and devices_in_listing counts them as ready, so "More than one iPhone is ready" named the simulator iPhone 17: skip anything whose reality is not "physical". The no-team message says to add an Apple ID even when the account is there but never finished signing in: say that whenever DVTDeveloperAccountManagerAppleIDLists holds an identifier. match_device needs the exact name, and iOS names the phone with a curly apostrophe (U+2019), so a typed straight one fails: treat them alike. Also seen: make ignores device= in lower case.

## Description

The user's answer to question 16 (November 17, 2026): "I thought it was talking about books with a transcript with what I remember having timestamps... Ok I just checked and it seems at least the content.md form doesn't have the timestamps, are those extractable? if so add todos to search by them and add them to the md." They are: transcript.json keeps every sentence with each word's start and end in milliseconds, and TextMouth writes content.md from it with a heading for each chapter and a paragraph for every few sentences, but no times. Write each paragraph's (or sentence's) start time into content.md as a hidden marker, as page markers are written, so that the reader, search, and exports can name and use the time; make the reading and every export ignore or show it as fits, and raise the reader's version so content.md is written again.

## Description

Remove Password is offered only in the unlock prompt, and once a password is remembered (on by default) the prompt never shows, so the person can't reach it. Add a Book menu command on the Mac for an unlocked protected book, and a control in the iPhone's Book Information, with its label, hint, and spoken result; check KeyboardReachabilityTests and the shortcut actions. Also from the same round: a test that forces Remove Password's write or rename to fail and checks the plain copy is gone.

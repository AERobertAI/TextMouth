## Description

Scripts/test/trap-lint.py --base 22a74c7fd (November 17, 2026) lists six REVIEW lines in TextMouthProductionTests/ExportDeepChapterExportTests.swift (about lines 733 to 773): shown.fulfill() and answered.fulfill() in the alert seam's closures, with no expectedFulfillmentCount or assertForOverFulfill = false. A regression that shows the question twice would then abort the test host on this Mac, which puts a crash report on the user's screen, instead of failing a test. Fix: set assertForOverFulfill = false where each expectation is made, and assert a call count of exactly 1, so a second call fails the test.

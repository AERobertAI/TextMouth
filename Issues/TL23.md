## Description

In train 1125-0148 the iPhone's interface tests failed (`LargeTextUITests.testSettingsHoldsAtTheLargestText`, job 2 of 2), and the GitHub run's conclusion was failure.
Yet the train's `summary.md` headline read "Verdict: PASSED", `run-summary.txt` ended in PASSED, and the board post to the agent read "train 1125-0148: PASSED; yours: 0 failures, 0 compile errors".
The headline and the post count only the Mac suite; the iPhone result is a separate line further down.
The agent found the failure by reading on, but an agent that trusts the headline would report a failing branch as green.

Fix: when a train runs iPhone tests, its verdict and its board post say PASSED only when the Mac suite and every iPhone job pass, and otherwise name the part that failed, such as "FAILED (iPhone: 1 failure)".
Test with made-up results: the Mac passed and the iPhone failed, both passed, the Mac failed and the iPhone passed, and no iPhone run.

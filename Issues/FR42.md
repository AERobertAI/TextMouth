## Description

Describe the pictures of a book that have no description of their own, on the device. Design: research/IMAGE-DESCRIPTIONS-2026-11-24.md: Vision's facts on every version, a sentence from the on-device language model on 26, and a caption from the picture with Foundation Models' Attachment on the 27 releases (which needs the 27 SDK, so Xcode 27).

Facts checked against Apple's pages on November 24, 2026: no public API gives VoiceOver's own description (VO-Shift-L, which uses Apple Intelligence by default); Attachment is introduced in 27.0; on 27, Apple Intelligence is on by default and can no longer be turned off. Apple's cloud model (PrivateCloudComputeLanguageModel) is also 27.0 only, needs the managed entitlement com.apple.developer.private-cloud-compute, and is without cloud API cost, within daily limits, for apps in the App Store Small Business Program with fewer than 2 million first-time downloads; Apple says expanded access will come for a fee. Whether TextMouth ever offers it is the user's choice (it sends a picture off the device).

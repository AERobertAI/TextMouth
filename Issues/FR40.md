## Description

The user, November 23, 2026: "I do want all the liblouis braille tables on iOS". The iPhone has no VoiceOver tables folder to read, so it bundles only English's 20 table files (293 KB). liblouis's whole set (485 tables in the Mac's copy of 3.34.0) is 14.0 MB as files, but 2.44 MB compressed with LZMA in one stream per name-prefix group (2.17 MB in one solid stream, 2.92 MB in one per file), measured on November 23. The plan is to ship 3.39.0's set, the vendored version, as one compressed pack with an index of each table's metadata and includes. Choosing a table unpacks it and the tables it includes into the app's caches folder at first use, and liblouis reads them there. The iPhone app grows by about 2.2 MB. FR32 (the table choice on the iPhone) needs this to offer more than English. Open questions: whether a Mac table's stored value (mac:<file>) reads with the iPhone's table of the same file name; the 3.39.0 set's own measurements; each table's license.

## Description

**B15 — A valid audio file whose sample format TextMouth can't read is called damaged.** Found November 16, 2026 by `review-floatrender` (Q4): the import probe's sentence "…is damaged or incomplete: its audio cannot be decoded. Get a fresh copy of the book…" (`AudioBookParser.swift:719`) would reach a 64-bit integer WAVE, which Core Audio reads and the import keeps as it is; a 64-bit integer CAF, converted first, ends with "Converting its audio failed: … (the converter ended with code 1)", which is true but names no cause. Fix: a sample-format refusal with its own sentence in a `…Wording` enum that names the format (for example "64-bit integer samples"), on both paths, with tests.

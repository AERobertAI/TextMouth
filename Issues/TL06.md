## Description

Train 1117-0527's 'iOS build of the merged tree' failed with 'xcodebuild ended with status 65 and no error line'. review-sampleformat found the cause in its log: a module-cache race in TextMouthBrailleLibrary.c ('_Builtin_stdint….pcm not found'), not the branch's code. Train 1117-0431 built the same app code and passed on its retry. Make run-ios-build.py name such a failure in its summary instead of 'no error line', and treat it as the stale-module retry (runner_module_cache.py) treats a stale module: empty the module caches and build once more.

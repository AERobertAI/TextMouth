## Description

Found by the FMT56 review, November 23, 2026, on the user's BARD sample: its braille page numbers stand at the top right of odd pages and run on across volumes. BraillePageAnalyzer reads them as print page numbers, so the page labels are plain counts, which drift from the book's real braille page numbers by about 60 pages by volume 14. This is the analyzer's existing behavior, so plain BRF imports have it too. Check where BANA's Braille Formats guidelines put the braille page number and the print page indicator before changing anything; per the rule on braille claims, verify against BANA, not from memory. Then read each correctly, and decide with the user which one Go to Page and page labels use.

## Description

**What's missing.** Musepack (.mpc) is in FFmpeg's build list and the import's sniff on both platforms, but no sample has ever been decoded on either. Parity holds only by construction.

**The fix.**
- Add a small Musepack sample under CC0: make it on a machine with Musepack's encoder (`mpcenc`), or find one under CC0. Add its `samples.tsv` line and its recipe, with no path of any one computer.
- Add it to `FFmpegImportRealTests` on both platforms: the same book on each, with its length and tags.
- Until a sample passes, the user docs don't promise Musepack.

**From** phoneffmpeg's question 5, and review-phoneffmpeg's answer to it (November 17, 2026).

## Description

**The user's plan (November 20, 2026).** "We can look into compression once we have all of the translations as data." With eleven languages the Mac app is 25,506,011 bytes; the language files are 4.7 MB of it, and FR36's second wave (twelve more) adds about 5 MB more.

**What is known.**
- Every language's `.strings` repeats the English keys: 151,774 bytes each.
- One binary `.loctable` for all languages stores the keys once but writes non-ASCII values in UTF-16; it saves nothing for Latin languages (TL18).
- TL18's squeeze (entries Foundation can do without, one-form plurals) saved about 94 KB over eleven languages.
- The deeper English cut toward 150 KB saves about 170 KB over eleven languages for each 10% cut.

**To study when every language is in:** the files compressed in the bundle and expanded into the app's caches on first launch (Foundation reads only uncompressed tables, so the lookup would go through a bundle in the caches); short keys generated at build time; the English cut; and what each costs at launch.

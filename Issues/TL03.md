## Description

Found November 16, 2026 by gotofont: make typecheck-ios and make typecheck-ios-tests compile the iPhone app and its unit tests, but not TextMouthiOSUITests, so a compile error in an interface test (train 1116-2106) is first seen on GitHub, where it fails a whole train. Fix: a type-check of the interface-test bundle with Xcode's SDK alone, as typecheck-ios-tests does for the unit bundle, run before every train that touches the iPhone, and named in common.md's steps.

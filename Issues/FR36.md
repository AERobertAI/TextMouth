## Description

**What the user asked (November 20, 2026).** "Have some agents work on other language files": Italian, French, Portuguese, then German, Russian, Ukrainian, then Simplified Chinese, Japanese, and Korean, "machine translated by agents", and "try squeezing all of the languages into 25 MB" (TL18).

**The plan.** The catalog's codes are `it`, `fr`, `pt-BR` (Brazilian Portuguese, Xcode's usual choice; Portugal's `pt-PT` can follow), `de`, `ru`, `uk`, `zh-Hans`, `ja`, and `ko`. With English and Spanish that makes the eleven languages of FR34.
1. One agent translates the glossary's terms into all nine first, marked `check`, so every translator of a language uses the same words.
2. Six translators a language, by the same disjoint area key files as Spanish's (`docs/developer/translation.md`, Translating at scale), in three rounds: the Romance languages, then German, Russian, and Ukrainian, then the three East Asian languages.
3. One consistency pass a language: control names inside sentences, one term each, and the glossary's proposals.
4. Every string `machine_translated`, for a native speaker's review; the plural rules of each language checked against Apple's own at run time (`LanguagePackPluralRules`).

**Size.** Each new language adds about 0.46 MB to each app (0.64 MB for Russian and Ukrainian, whose letters take two bytes), so the nine bring the Mac app from 21.9 MB to about 26.2 MB before TL18.

## Description

A crash report of Nov 18, 2026 (an old 0.4.10 build, opened from Finder's Open With with a ZIP; 3 seconds after launch): the main thread aborted in AttributeGraph (AG::Graph::value_set precondition_failure) from BookReaderWindowView.init's StateObject autoclosure -> ReaderViewModel.init -> LibraryViewModel.registerOpenBook -> the @Published openBookIDs setter -> ObservableObjectPublisher.send -> AttributeInvalidatingSubscriber -> GraphHost.asyncTransaction -> flushTransactions, inside GraphHost.flushGlobalTransactions. A ZIP import, the launch sweeps, and the braille table load were running. Main has the same path: ReaderViewModel.init still calls registerOpenBook, which inserts into the @Published set at once, while the reader window builds the reader during SwiftUI's update. Fix: keep the registration's synchronous truth (openReaderCounts, the open-book checks, FR04's audio originals) and publish openBookIDs outside the view update; check the other models built in StateObject autoclosures for the same pattern. No crash test on this Mac: test that building a reader publishes nothing on the library model during init, that the set holds the book after the main queue's turn, and that a register then unregister in one turn leaves no book behind.

## Description

**What happens.** On the iPhone, a hybrid WavPack book added through Open Book or "Open in" loses its correction file. `X.wv` arrives without `X.wvc`, and it becomes AAC rather than Apple Lossless, with no word why.
- `PhoneImportCopy.swift` (about lines 26 to 31, and 151 to 160) copies each picked or sent item alone into its own scratch folder. Open Book offers no type for `.wvc` (`PhoneAddToLibrarySheet.swift:27`, `FileImportService.swift` about 3206 to 3208). So `stageContent` finds no companion.
- Import Folder keeps the `.wvc`, since it copies every file, and so does a ZIP.
- On the Mac, the import reads the file beside it, so the same book is Apple Lossless.

**Found by** review-phoneformats, November 18, 2026 (item 1, `build/orchestrator/nov17/review-phoneformats-report.md`), on `phone/own-lossless`, which lets the iPhone take WavPack.

**The fix.**
1. Now, in docs: a hybrid WavPack book keeps its full quality on the iPhone only through Import Folder or a ZIP.
2. An import notice, a sentence in a `…Wording` enum, returned through `convertImportedAudio`'s notice when a hybrid file converts lossy for want of its `.wvc`. It points to Import Folder or a ZIP.
3. Later: let Open Book take a `.wvc`, and copy the pair into one scratch folder.

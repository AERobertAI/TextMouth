## Description

**FU01 — drop the upstream patches.** The bundled FFmpeg is 9.0.2 with five upstream patches (Scripts/vendor/ffmpeg/patches/, pinned in PATCHES in Scripts/vendor/ffmpeg/build.py): 968e9e948ed8c9ba90dbc875e60b843c755cf4ba (CVE-2026-125104, apedec), 5d59b7c45d7142bddd13ddc8891e72c5c7dc991b (CVE-2026-125171, mpc7), 7145d13201c9f9c5253f40295714faa4f4ada1a0 (CVE-2026-125182, cook), 972fe1ccd326538fe9a6b5d5094b7880b5443429 (CVE-2026-125221, flac_parser), 90f5e61a1da2dcc0050169af8ca593530f26071b (CVE-2026-125224, vorbis_parser). When FFmpeg 9.0.3 (or a later release) includes the five commits, move the pin to it (the four FFMPEG_ lines and the GITHUB_ pin, comparing the two trees again), empty PATCHES, delete the patches folder, regenerate the README (build.py --readme) so it says the release is unchanged, and change Credits.rtf and BundledLicenseTests to match. Check each commit's presence in the new release's source or ChangeLog before dropping it; a patch the release lacks stays.

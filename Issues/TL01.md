## Description

Found November 16, 2026 by docspass1116 while documenting imagecache's merge (8400f9baa). Scripts/agents/run-on-runner.py runs a shard's xcodebuild with -resultBundlePath <out>/result.xcresult and, when the build fails on 'has been modified since the module file', empties the module caches and runs the same command again. The first try leaves result.xcresult behind, and xcodebuild refuses a -resultBundlePath that already exists, so the retry cannot run and the shard still fails. The iPhone build (run-ios-build.py) passes no result bundle, so its retry is unaffected. Fix: before the retry, move the first try's bundle aside (for example result.first-try.xcresult, kept for diagnosis) so the retry writes result.xcresult, and test it with a stand-in xcodebuild that refuses an existing bundle.

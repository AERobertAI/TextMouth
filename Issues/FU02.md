## Description

On the Mac, liblouis runs in a helper program, so a crash ends the helper alone. On the iPhone it runs inside the app (DR34, 1820f9853), so a liblouis crash, or liblouis's exit(3) when memory runs out, ends TextMouth. Accepted for DR34 (phonebraille's question 4), with the input caps, the bundled tables only, and the Mac's limits keeping the risk small. FFmpeg's iPhone half (FMT54) will share it. Revisit if such a crash is ever reported, or if iOS offers a way to run the work apart.

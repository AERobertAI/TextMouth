## Description

Found November 16, 2026: 'issuelib.py comment DOC03 --as orchestrator "text"' fails with 'unrecognized arguments', because argparse consumes the optional TEXT positional when it reads ID, before --as. Only 'comment ID "text" --as NAME' works. The same may hold for other commands with an optional positional after options. Fix: parse with parse_intermixed_args, or make the text an option (--text), and test both orders.

## Description

On macOS 27.2.1 (Nov 27), two small test programs built with Xcode 27.2 were killed (SIGKILL, exit 137, with a crash report) as they called sandbox_init("pure-computation", SANDBOX_NAMED), with or without Claude Code's shell sandbox, by the profile's name or by the library's constant. They were ad-hoc signed and built with the 27.2 SDK, so the signed helper may differ. If the helper is killed too, every FFmpeg import fails on macOS 27: the user checks with one import (an Ogg or Opus file) after installing. If it is, the helper needs another confinement, such as the App Sandbox entitlement with its input passed as a descriptor. No further probes on the Mac: each left a crash report.

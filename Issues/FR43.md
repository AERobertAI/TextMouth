## Description

The user asked on November 25, 2026 to sync the library between the Mac and the iPhone, especially through iCloud, "working before Saturday": each device keeps its whole library, its changes ("deltas") are synced at launch, every hour, when the network comes back, and on a button, and the cloud holds every book's data, "like a version control system".
This is option C, the cloud store, of `research/LOCAL-FIRST-LIBRARY-RESEARCH-2026-11-13.md`, whose recommendations the user took on November 14 (its Phase 0 shipped in 0.4.11).
The build plan is `research/CLOUD-SYNC-BUILD-PLAN-2026-11-25.md`: a TextMouth Sync folder in iCloud Drive, every book's files named by SHA-256, each device's changes kept in an outbox on its own disk until iCloud reports them uploaded, merged by fixed rules; four branches from `sync/base` (sync-core, sync-store, sync-mac, sync-iphone), for a release on Friday, November 27.

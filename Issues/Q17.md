## Description

Since 0.5.4 put the whole interface in Spanish, both SpanishUITests fail with "The reader never opened": TextMouthUITestCase.launchIntoTheReader waits for app.buttons["Play"] and a value other than "Loading", and in Spanish the button is "Reproducir" and the value "Cargando". The trains that merged the Spanish ran the iPhone's interface job only before the whole-app Spanish (1119-1051), so 0.5.4 shipped with them failing; trains 1120-0048 and earlier report the same two failures. Fix: launchIntoTheReader takes the Play label and the loading value, and SpanishUITests passes the catalog's Spanish.

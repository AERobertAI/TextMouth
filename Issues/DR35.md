## Description

**DR35 — Read the description of a picture in a Word or rich text document.** From the ChatGPT docs review of November 16, 2026 (suggested priority P2; list item 24). Docs: `docs/user/what-textmouth-reads.md`, "Emphasis, lists, tables, pictures, and fields": "Pictures and embedded objects are silent, except in OpenDocument text, where a picture, formula, or chart is read as its description", and "Pictures are silent in Word and rich text documents." (the Word 6 and Word 95 page also lists pictures as not read). Code: the shared readers, `Parsers/DOCXParser+Converter.swift` (a .docx keeps the description in plain view of the reader, so it is quick), `RTFBlockBuilder.swift` (nearly as simple), and `WordDocumentHTMLWriter.swift` and `WordDocumentLegacyText.swift` (a .doc keeps it deeper in the file, so later or not at all). HTML, EPUB, MOBI, KFX and OpenDocument already read a picture's description. Platform: both at once, since the readers are shared; no iPhone gap. Related: DR17, DR21. (question only until now: `humanQuestions/2026-11-06.md` question 2, recommended A: read them where the file holds one; the alternative B leaves these formats silent. Unanswered.)

## Recommended Next Work

1. Move single-file import work off the main thread. **Difficulty: 7/10.** This is now the most direct user-visible performance improvement and should establish the import-operation structure used by later concurrency fixes.
2. Serialize ZIP imports or isolate each import's progress/dialog state. **Difficulty: 7/10.** Per-file errors are visible, but concurrent ZIP operations still share progress and dialog state.
3. Serialize current- and next-chapter TTS rendering with consistent limits. **Difficulty: 7/10.** This removes competing render jobs and unbounded next-chapter work without requiring the broader actor-isolation rewrite.
4. Centralize global Now Playing and remote-command ownership across reader windows. **Difficulty: 8/10.** Multiple windows currently compete for process-global media state.
5. Fix Unicode coordinate consistency across search, substitutions, and speech offsets. **Difficulty: 8/10.** This needs a deliberate coordinate-system migration and multilingual regression fixtures.

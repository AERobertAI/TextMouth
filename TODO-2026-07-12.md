## Recommended Next Work

1. Copy and validate externally opened `.tmb` packages before adoption. **Difficulty: 6/10.** This is the next self-contained item and prevents library entries from depending on removable or security-scoped external storage.
2. Treat book/folder moves and `bookInfo.json` updates as one transactional batch. **Difficulty: 8/10 plus the dependent 4/10 metadata item.** Fixing metadata alone would record incorrect locations when a disk move fails.
3. Redesign Trash failure handling together with deletion transactions and confirmation UI. **Difficulty: 5/10 locally, higher in context.** Silently keeping the package is safer than permanent deletion but can desynchronize the library unless model removal also becomes conditional.
4. Move single-file import work off the main thread. **Difficulty: 7/10.** This is the most direct remaining performance improvement after persistence serialization.
5. Serialize ZIP imports or isolate each import's progress/dialog state. **Difficulty: 7/10.** Per-file errors are now visible, but concurrent ZIP operations still share mutable UI state.

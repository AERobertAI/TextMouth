## New Issues Found This Session

### Critical (Fixed)

#### N1. Force Unwrap in waitForAsync
- **File:** `ReaderViewModel.swift:1576`
- **Category:** Crash Risk
- **Description:** `result!` force unwrap after semaphore wait. If async Task is cancelled or race condition occurs, crashes the app.
- **Status:** **FIXED THIS SESSION** — replaced with guard let + error throw

#### N2. Path Traversal in EPUB Extraction
- **File:** `EPUBParser.swift:57`
- **Category:** Security
- **Description:** Chapter paths decoded from XML with `removingPercentEncoding` without checking for `..` or absolute paths. A malicious EPUB could reference paths outside the archive.
- **Status:** **FIXED THIS SESSION** — added path traversal guard

### Major (Open — Fix Next Session)

#### N3. SpeechService Position Timer Not Cleaned Between Starts
- **File:** `SpeechService.swift`
- **Category:** Resource Leak
- **Description:** `startPositionTracking()` called from multiple code paths. If called while timer already running (e.g., during `resume()`), a second timer accumulates and both fire, causing duplicate position updates and wasted CPU.

#### N4. TextSubstitutionService Offset Mapping Issues
- **File:** `TextSubstitutionService.swift:140-235`
- **Category:** Logic Bug
- **Description:** Complex offset mapping in `transform()` and `buildOffsetMap()` becomes unreliable when multiple substitution rules apply overlapping patterns. Each rule's replacements affect the indices used by subsequent rules, causing character offset tracking to get out of sync with visual highlighting. Bookmarks and seeking may jump to wrong positions.

#### N5. AudioPlaybackService Duration Race Condition
- **File:** `AudioPlaybackService.swift:48-56`
- **Category:** State Management
- **Description:** `load(url:)` loads duration asynchronously with `Task { @MainActor in }`. Rapid file switches can cause the old task to overwrite the new file's duration. No cancellation mechanism exists.

#### N6. Missing VoiceOver Rotors for Library Folders and Bookmarks
- **File:** `LibraryView.swift`, `BookmarkPanelView.swift`
- **Category:** Accessibility
- **Description:** Library has a rotor for books but not for folders. VoiceOver users cannot efficiently navigate folder structure. BookmarkPanelView also lacks a rotor. BreadcrumbBar container nesting may cause jumbled VoiceOver announcements.

#### N7. SleepTimerService Fade Timer Can Fire Multiple Times
- **File:** `SleepTimerService.swift:40-121`
- **Category:** Timing Bug
- **Description:** If `stop()` is called while fade timer is running, the old fade closure may continue from the timer queue. `expire()` can be called from multiple code paths (countdown, heading boundary, document end), potentially calling `startFadeOut()` multiple times, causing audio to fade multiple times or the completion callback to fire after user stopped playback.

#### N8. MetadataEditorView "Done" Was Misleading
- **File:** `MetadataEditorView.swift:24`
- **Category:** Accessibility / UX
- **Description:** "Done" button only dismissed without saving. Blind users would press it expecting to save, losing edits.
- **Status:** **FIXED THIS SESSION** — renamed to "Close"
